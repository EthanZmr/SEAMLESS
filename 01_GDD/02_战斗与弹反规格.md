## 1. 核心动词

| 动词 | 阿针 | 阿绫 |
|---|---|---|
| 轻击 | 3 段针刺，快，低伤 | 4 段故障刃，更快，高伤 |
| 重击 | 掷针钉住敌人/锚点 | 过载斩，破防 |
| 纤维 | 拉近/摆荡/缝敌/缝自己 | 数据鞭，范围短路 |
| 弹反 | 纤维绷紧接住接缝 | 故障相位接住接缝 |
| 切换 | 故障冲击波，取消后摇 | 同左 |

**缝**：花 1 纤维，把两个目标连在一起（敌人-敌人、敌人-墙、自己-伤口）。战斗中用于控场/回血；关卡中用于造桥/固定。
**拆**：敌人接缝暴露时，抓取并撕开；触发布料/义体爆裂，掉落核心/纤维；对精英/Boss 是处决。

## 2. 双意识与同步率

### 2.1 姿态

| | 阿针 | 阿绫 |
|---|---|---|
| 定位 | 控场/修复/稳 | 爆发/故障/玻璃大炮 |
| 伤害 | 100% | 120% |
| 完整度消耗 | 标准 | 每秒 -2 |
| 同步率 | 行动时 -2/秒 | 行动时 +4/秒 |
| 特色 | 缝、格挡、造桥 | 过载、短路、闪现 |
| 受击 | 标准 | +20% 伤害 |

### 2.2 同步率 0–100

- 初始 30。
- 阿针行动：-2/秒；阿绫行动：+4/秒；普通弹反 +6；完美弹反 +6 且冻结 2s；失败 +10。
- **100**：阿绫强制接管 8 秒。全属性强化、招式变为阿绫版、玩家失去控制；结束后同步率回到 50，完整度 -20。
- **0**：阿针进入“稳定”，完整度 +2/秒，直到 20。
- UI：屏幕底部一条会抖的线；接近 100 时线变红、画面出现故障噪点；接近 0 时线变蓝、呼吸声变慢。

### 2.3 切换

- 输入：`switch_consciousness`。
- 动画：0.15s；带一次故障冲击波（半径 2 格，打断杂兵轻击）。
- 冷却：0.4s。
- 完美切换（在敌人攻击命中前 0.1s 内切换）：触发“同步弹反”的简化版——不换姿态，给 0.2s 无敌 + 纤维回满。作为高阶技巧保留。
- 切换时同步率 ±5（切阿绫 +5，切阿针 -5）。

## 3. 完整度（替代血条）

- 100 点；受击 -10~-25；阿绫姿态额外 +20% 伤害；同步率满接管结束 -20。
- 受伤表现：身体局部花屏、断线、火花；无红色血条。
- 恢复：阿针“缝自己”花 2 纤维，+15，耗时 1.2s（可被打断）；检查点回满；阿绫“过载”可吸血但涨同步。
- 0：断线。回到最近“针眼”，完整度 50，同步率 20，敌人重置。

## 4. 弹反（方案 A：同步弹反）

### 4.1 输入与状态机

- 独立弹反键：`parry`（手柄 Y，键鼠 K）。
- 轻按：`ParryActive` 0.20s；前 0.08s 完美，后 0.12s 普通。
- 长按超过 0.20s：`Guard`，减伤 50%，不涨同步，无反击；松开或受击结束。**（W1 未实现）**
- 窗口结束/松手：`ParryRecovery` 0.20s；失败硬直 0.40s；冷却 0.40s。
- 输入缓冲 0.15s；完美弹反返还冷却；普通弹反冷却 0.40s。

```
Idle ──tap──> ParryActive(0.20s)
                 ├─ hit in 0–0.08s ──> Perfect
                 ├─ hit in 0.08–0.20s ─> Normal
                 └─ no hit ──> Whiff/Recovery
Idle ──hold>0.20s──> Guard
Perfect/Normal ──> Counter/Recovery ──> Idle
```

### 4.2 判定结果

| 结果 | 条件 | 效果 |
|---|---|---|
| 完美弹反 | 命中前 0–0.08s | 慢放 0.3s；另一意识接管 0.6s 反击；同步冻结 2s；接缝暴露 1.5s；伤害 +50%；叠同步层（最多 3）；1s 内“拆”必中 |
| 普通弹反 | 0.08–0.20s | 敌人硬直 0.5s；接缝暴露 0.5s；同步 +6；可接“拆” |
| 格挡 | 长按 | 减伤 50%；不涨同步；不能反击 |
| 失败 | 窗口外/冷却中 | 攻击照常命中（即惩罚）；同步 +10；硬直 0.4s；阿绫可能抢话 |

**同步层**：完美弹反叠 1 层，最多 3 层；每层 +10% 反击伤害；被击中清零。

### 4.3 阿绫报点

- 同步 >30：攻击前 0.3s 报方向（“左”“上”“别动”），窗口 +0.02s。
- 同步 <30：沉默，窗口标准。
- 同步 >70：花屏、抢话、窗口 +0.06s，但完美弹反后更容易触发接管（接管阈值临时降到 90）。

### 4.4 完美弹反奖励：缝住攻击

完美弹反后按住 `parry` + 方向，花 2 纤维，把敌人的攻击缝到另一目标：
- 武器缝到墙/地：缴械。
- 子弹缝回射手/另一敌人：反射。
- 激光缝到地面：绊索。
- Boss 的“剪承重缝”缝回去：阻止场地变化。

仅精英/Boss 开放，避免日常操作过载。

## 5. 敌人攻击标注规范

每个攻击必须实现：

| 字段 | 说明 |
|---|---|
| `parryable` | true（白缝）/ false（红招） |
| `telegraph` | 0.3–0.5s；白缝亮起/红光亮起 |
| `seam` | 武器/肢体/核心；弹反后暴露的位置 |
| `multi_hit` | 每段独立窗口；最后一段完美奖励更高 |
| `perfect_reward` | 开哪道缝、是否可处决 |
| `reflect` | 投射物弹反后的行为 |
| `sfx` | 弹反音效层 |

**杂兵**

| 敌人 | 招式 | 类型 | 完美奖励 |
|---|---|---|---|
| 清道夫 | 三连棍 | 可弹 ×3 | 第三下完美 → 胸缝，可拆 |
| 清道夫 | 盾冲 | 红 | 必须闪避；撞墙硬直可拆 |
| 广告无人机 | 广告弹幕 | 可弹 | 反射碎片，追踪其他敌人 |
| 广告无人机 | 自爆俯冲 | 红 | 闪现/远程击落 |
| 记忆水蛭 | 扑咬 | 可弹 | 扯出核心，回 2 纤维 |
| 记忆水蛭 | 吸附 | 不可弹 | 快速击杀/切阿绫短路 |

**裁断者**

| 招式 | 类型 | 弹反结果 |
|---|---|---|
| 三连剪 | 可弹 ×3 | 第三下完美 → 肩缝；普通 → 硬直 |
| 过顶重剪 | 红 | 必须闪避/阿绫相位 |

| 裁断网格 | 可弹任意线 | 短路，全场眩晕 2s；完美 → 全反射，跳阶段 |
| 旋风剪 | 红 | 闪现穿过；完美闪避后弹反收招 |
| 剪承重缝（转阶段） | 可弹 | 把缝“缝回去”，阻止场地倾斜，耗 2 纤维 |

## 7. 游戏感

- 命中停顿：轻击 75ms / 105ms / 160ms（三段递增，对齐代码 `[0.075, 0.105, 0.160]`）；挑空 110ms；空中 70ms；弹反 60ms；完美 120ms；处决 180ms。
- 相机震动：轻击 0.05；重击 0.12；完美 0.18；处决 0.3；可关。
- 手柄：轻击短震；弹反双震；完美双脉冲；切换长震。
- 音效：针（金属高频）、纤维（弦鸣）、弹反（“铮”+ 低频“咚”）、完美（反转混响 + 心跳）。
- 特效：火花、机油、纤维白线、故障色差、布/义体碎片。

## 9. 调参与验收

- 目标：普通玩家 10 分钟内完美弹反率 20–30%；高手 60%+。
- 如果没人用普通弹反 → 完美窗口太宽/普通收益低。
- 如果全程龟 → 同步率惩罚不够/格挡太强。
- 如果没人切阿绫 → 完美弹反的交还控制不明显。
- 验收：5 人试玩，3 分钟内至少 3 人打出完美弹反；无人说“这不就是只狼”。
