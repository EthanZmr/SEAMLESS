## 0. 一句话

A 教“缝”，B 教“爬 + 钩”，C 考“墙跳 + 钩 + 缝”的组合；每个区域只有**一条主路 + 一条精通路**，两条路都在同一个检查点收束，不再出现第三条半路线。

## 1. 玩家度量（所有几何按这个算）

| 项 | 数值 | 用途 |
|---|---|---|
| 跑速 | 220 px/s | 横向距离 |
| 跳跃初速 / 重力 | -600 / 1400 | 跳高约 128px，滞空约 0.86s |
| 平地跳距 | 约 188px | 安全 gap ≤120，硬 gap ≤160，教学 gap 200 必须用能力 |
| 二段跳 | -540 | 追加高度约 104px，不用于常规跳距 |
| 钩索 | 320px / 680px/s | 锚点必须在屏幕内可读 |
| 攀爬 | 132px/s | 竖井/梯缝 |
| 墙跳 | 横向 360 / 纵向 -560 | 墙井宽度 120–140 |
| 玩家碰撞 | 约 40×64 | 开口至少 100，推荐 120 |

## 2. 现有问题 → 重设计判断

| 现有问题 | 根因 | v2 处理 |
|---|---|---|
| A 只是走廊，没有教学 | 没有“必须使用能力”的门 | A 加 200px 断桥，必须 U 缝桥；失败会坠落，但检查点很近 |
| B 有梯子、墙井、钩桥三条上法 | 三条半路线并列 | B 只保留“梯子→屋顶→钩索”一条高路线；删 B 墙井、旧钩桥 |
| C 看起来像三条半路线 | 旧高台 + 竖井 + 猫道叠在一起 | C 只保留“地面 + 竖井上层”；删旧高台；电力缝放猫道出口 |
| 检查点太远 | 最近针眼在 1720 | C 入口 1280 加针眼；D 入口 1720 保留 |
| 失败没有代价 | 没有坠落死亡 | A 断桥下方是坠落区；C 竖井失败落回地面，不秒死 |
| 靠标签指路 | 文字多、地标弱 | 每区只留 1 条短提示；用绿色梯缝、粉色锚点、白色针眼、霓虹“缝”字做地标 |

## 3. 总体结构

```
A 诊所后巷            B 雨市入口                 C 霓虹巷
0 – 620               620 – 1260                 1260 – 1800
┌──────────┐          ┌───────────────┐          ┌──────────────────┐
│ 诊所      │          │ 梯塔  屋顶     │          │ 竖井   屋顶/猫道   │
│ 断桥 200  │  →       │  ↓      ↘ 钩索 │  →       │  ↑      ↘ 电力缝   │
│ 缝桥      │          │ 低路 门/截线者  │          │ 低路 截线者/短路门  │
└──────────┘          └───────────────┘          └──────────────────┘
  教 U                   教 W + H                  考 Space + H + U
```

- **A**：1 场轻战斗 + 1 个必须缝的断桥。没有复杂分叉。
- **B**：低路（战斗 + U 开门）和高路（爬塔 + 屋顶战斗 + H 钩过缺口）二选一，C 入口收束。
- **C**：低路（截线者 + 短路上锁）和高路（双墙竖井 + 屋顶战斗 + H 猫道 + 电力缝）二选一，D 入口收束。
- 两条路都不是死路，也不是“纯更快”：低路更稳、有补丁；高路更险、有电力缝/跳过门。

### 5.5 A1 的时长与内容预算

玩家跑速 220px/s，A–C 若要 10–12 分钟，不能只靠 1800px 骨架。按“1 分钟需要约 450–550px 有效路线（含战斗/攀爬/钩索）”估算，A–C 需要约 **5000–6100px**，并增加 4–6 个有决策的段落。A1 采用 **6100px**：

| 区 | 宽度 | 目标时长 | 新增内容 |
|---|---:|---:|---|
| A | 0–2400 | 3–4 分钟 | A1 诊所后巷、A2 吊桥市场（两条缝/钩/排水沟）、A3 天台墙跳井 |
| B | 2400–3900 | 4.5–5 分钟 | 低路战斗房、塔内两层、屋顶敌人、钩缺口、猫道、低路闸门 |
| C | 3900–6100 | 5–5.5 分钟 | 低路截线者/补丁/短路闸门、竖井中段抓边、屋顶战斗、钩猫道/电力缝 |
| **合计** | **6100px** | **10–12 分钟** | 8–9 个敌人位、4 接缝（A 两段桥各一）、2 补丁、3 针眼 |

检查点：A `1150` / B `2520`（原 1720 东移）/ C 入口 `3900` 待 W6-02 实现；A 的两段缝桥分别跨 200px + 200px，中间安全岛；B 塔内两层让爬塔不是直线；C 竖井中段加抓边层，失败不直接掉回地面。D–F 另排 13–18 分钟，合计 25–30 分钟。

原 1800px 图只是“路线语法”示意，A1 的实际坐标在 W6 的 `level.gd` 重排文档里逐段落地；不再把骨架时长当成品时长。

## 7. 失败与恢复

- A 断桥：掉下 y>740 → 回 A 入口；不扣完整度，3 秒内重来。
- B 高路：掉下 → 回 B 地面；爬塔重来，不死亡。
- C 竖井：掉下 → 抓边/地面；C 入口针眼 1280 重来。
- C 低路：截线者伤害；死亡回 C 入口。
- D 入口 1720 针眼：Boss 前最后检查点。
- 不在 W6 加“即死尖刺/无人机”；这些留到 W7 D–F。
