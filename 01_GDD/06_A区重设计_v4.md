# A 区重设计 v4：吊桥市场

> A 不是教学段。这里默认玩家已会移动、二段跳、冲刺、攀爬、钩索、缝桥、弹反。
> A 的任务是：用同一套动作做一次有代价的路线选择，而不是把三条平台叠在一起。

## 1. 玩家度量（已从实现取数）

| 项目 | 数值 |
|---|---|
| 跑速 | 220 px/s |
| 冲刺 | 560 px/s |
| 跳跃初速 | -600 px/s |
| 重力 | 1800 px/s² |
| 最大跳高 | 约 100 px |
| 最大跑跳距 | 约 147 px |
| 标准安全跳距 | 100–140 px |
| 硬跳距 | 170–188 px（二段跳/冲刺可过） |
| 钩索射程 | 320 px |
| 攀爬速度 | 132 px/s |

因此 A 的**关键跨越不靠 200 px 缺口**，而靠**高度、层级、单向落点**。
200 px 缺口对冲刺/二段跳没有压力，只适合作为“掉下去也不死”的排水沟入口。

## 2. 空间：一个中庭，四条路线

A 内容范围 `x=0–1200`（核心中庭 0–900，900–1200 是出口街面；B 从 1360 开始），垂直 `y=240–800`。

```
y=240   [左屋顶 220–380]        [广告牌 620–820]        [右屋顶 900–1080]
              │ H钩索(560,210)        │ U高缝(700,240)       │
y=440   [雨棚A 300–420] [雨棚B 520–640] [雨棚C 740–860]
              │ 绿梯320        │                     │ 绿梯760（回路）
y=560   [街面 0–300][市场 300–460]  ✕ 460–660  [市场 660–820] ✕ 820–900 [街面 900+]
y=800                         [排水沟 520–900]  补丁700
```

- **低路（承重缝）**：街面 → 缝 410 的 240px 桥 → 市场双敌 → 东侧针眼。
- **中路（绿梯/雨棚）**：绿梯 320 → 雨棚 A/B/C → 东侧落点；可从东侧绿梯 760 爬回雨棚，形成回路。
- **高路（钩索+高缝）**：绿梯 320 → 雨棚 A → 绿梯 360 → 左屋顶 → 钩 560 → 广告牌 → 高缝 700 → 右屋顶 → 单向落东侧。
- **排水沟（失败回收/支路）**：市场 820–900 的缺口掉下去 → 排水沟 → 补丁 700 → 绿梯 900 回东侧。

## 3. 三条路线的代价

| 路线 | 机制 | 代价 | 收益 |
|---|---|---|---|
| 低路 | U 缝桥 410 | 正面打市场双敌 | 最短、最稳 |
| 中路 | 绿梯 + 雨棚跳跃 | 需要读层、容易落回街面 | 绕开市场正面，保留回退 |
| 高路 | 钩索 560 + 高缝 700 | 左屋顶到广告牌必须钩；右屋顶只能单向落 | 绕开市场双敌，拿高位 |
| 排水沟 | 从缺口落下 | 单向、黑暗、无战斗 | 补丁；从东侧回来 |

**没有战斗门，没有空气墙。** 路线选择靠空间代价，不靠锁。

## 4. 回路与失败回收

- 雨棚 C → 东侧落点 → 绿梯 760 → 雨棚 C：中路可回退。
- 广告牌 → 落市场/雨棚 C：高路可主动下探，不是死路。
- 市场缺口 → 排水沟 → 绿梯 900 → 东侧：失败变成支路，不是读档。
- 右屋顶 → 东侧是单向落点；想再上高路必须从入口重走，这是高路的代价。

## 5. 战斗与节奏

| Beat | 位置 | 强度 | 内容 |
|---|---|---|---|
| 入口 | 180 | 0.2 | 单个清道夫，确认操作 |
| 第一选择 | 410 | 0.4 | 缝桥 / 雨棚 / 观察高路 |
| 市场 | 700/780 | 0.8 | 截线者 + 清道夫，正面压力 |
| 高路 | 680 广告牌 | 0.6 | 单个清道夫，窄平台 |
| 排水沟 | 700 | 0.1 | 补丁，休息 |
| 出口 | 1000 | 0.3 | 针眼，回望三层 |

## 6. 可读性

- 入口一眼能看到：左绿梯、左屋顶、中央广告牌、右屋顶、市场缺口。
- 只保留 2 条提示：
  - “街面 / 雨棚 / 屋顶 / 排水沟：掉下去不是死，是另一条路”
  - “高路：左屋顶 H 钩索 → 广告牌 U 高缝 → 右屋顶”
- 不在每个平台重复标签；不给每个接缝加说明。

## 7. 验收

1. 低路：缝 410 → 过桥 → 打市场双敌 → 到 1000 针眼。
2. 中路：绿梯 320 → 雨棚 A/B/C → 东侧落点；绿梯 760 可回。
3. 高路：绿梯 320/360 → 左屋顶 → H 钩 560 → 广告牌 → U 高缝 700 → 右屋顶 → 东侧。
4. 排水沟：从 820–900 缺口落下 → 补丁 700 → 绿梯 900 回东侧。
5. 任意路线不软锁；掉进排水沟不死。
6. A 首通 2.5–3.5 分钟（待真人计时）。

## 8. 已知取舍

- A 仍有可选低路，速通玩家会走最短线；这是有意的“熟练度捷径”。
- 高路的独占收益目前是“绕开市场双敌 + 高位”，还没有 A 专属补丁；若实测没人走高路，下一步把 A 补丁从排水沟移到右屋顶。
- A 不承担教学；教学关另做。
