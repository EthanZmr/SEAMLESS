# A 区重设计 v5：三街区（0–2400）

> 2026-10-21。A 不是教学段；默认玩家已会移动、二段跳、冲刺、攀爬、钩索、缝桥、弹反。
> A 的任务是用同一套动作穿过三个不同空间，而不是把三层平台叠成一条更长的走廊。
> 本文取代 v4 的 1200 单中庭。

## 1. 度量（实现取数）

| 项目 | 数值 |
|---|---|
| 跑速 | 220 px/s |
| 冲刺 | 560 px/s |
| 跳跃初速 | -600 px/s |
| 重力 | 1800 px/s² |
| 最大跳高 | 约 100 px |
| 最大跑跳距 | 约 147 px |
| 钩索射程 | 320 px |
| 攀爬速度 | 132 px/s |

A 的关键跨越靠**高度差、单向落点和路线回收**；200px 缺口对冲刺/二段跳没有压力，只作为低路缝桥与排水沟入口。

## 2. 三个空间

### A1 · 诊所后巷（0–900，其中 600–900 是过渡街面）

- 安全屋/针眼 `(120,560)`；诊所屋顶 `(80,440,180,16)`，绿梯 `(160,440,26,180)`。
- 第一个清道夫 `(360,560)`；从屋顶可落到其身后。
- 600–900 是进入市场的过渡街面，不设战斗门。
- 作用：给玩家一次“爬上去、绕过去”的低风险选择。

### A2 · 吊桥市场（900–1800）

- 低路：缝桥 `(1010,560)` 跨 `1060–1260`；市场地面 `1260–1420`；双敌 `(1300,560)`、`(1380,560)`；东侧针眼 `(1600,560)`。
- 中路：雨棚 `(900,440,120,16)`、`(1120,440,120,16)`、`(1340,440,120,16)`；绿梯 `920`、`960`、`1360`；可回环。
- 高路：左屋顶 `(820,280,160,16)` → 钩点 `(1200,210)` → 广告牌 `(1200,240,220,16)` → 高缝 `(1300,240)` → 右屋顶 `(1500,280,180,16)` → 单向下落。
- 排水沟：缺口 `1420–1500`；沟底 `(1120,800,380,80)`；补丁 `(1300,780)`；绿梯 `(1488,620,26,180)` 回东侧。
- 高路哨兵 `(1280,220)`；入口清道夫 `(820,560)`。
- 作用：低/中/高三条真实路线，全部收束到 1600 针眼；掉进排水沟是路线，不是死亡。

### A3 · 天台栈道（1800–2400）

- 低路：街面清道夫/截线者；截线者 `(1900,560)`；针眼 `(2320,560)`。
- 高路：屋顶 `(1960,440,180,16)`，绿梯 `(2000,440,26,180)`；墙跳井 `(2040,240,24,320)` / `(2160,240,24,320)`；顶部栈桥 `(2040,220,360,18)`；栈桥清道夫 `(2250,200)`。
- 出口：栈桥东端 2400，落到 B 入口街面；B 塔从 2560 开始。
- 作用：把 A2 学到的墙跳/攀爬放进一个短而硬的垂直段，作为进入 B 前的最后一次路线选择。

## 3. 节拍

- A1 0:00–0:40：低风险，建立“可以绕”。
- A2 0:40–3:00：主市场，三条路线+排水沟回收；一次针眼。
- A3 3:00–4:00：短垂直段，墙跳井；一次针眼。
- 目标：首次 3–4 分钟；熟练 2–2.5 分钟。A–C 总计仍以 10–12 分钟为目标，B/C 后续扩段。

## 4. 为什么不是继续加长

1200 的问题是“同一中庭横向拉长”，玩家仍能冲刺直过。2400 改成三个不同空间：A1 绕、A2 选、A3 爬；每段有独立构图和针眼。若仍觉得小，下一轮应加 B/C 与遭遇密度，而不是把 A 拉到 4000。

## 5. 验收

- A1 诊所屋顶可上，第一敌人可绕；掉下不卡死。
- A2 低路缝桥可过；高路钩索/高缝可过；排水沟可回东侧。
- A3 绿梯上屋顶，墙跳井可到栈桥，栈桥可到 B；不卡住。
- 三次针眼（120/900/1600/2320 中至少三个）能记录。
- 首次 3–4 分钟；若 90 秒内跑完，视为仍太短。

## 6. 已知短板

- A1 仍偏安全；第一场战斗可跳过。
- A3 高路是可选，低路可直达 B；需要真人确认“值得爬”。
- 白盒标签多，正式美术前会再收一次视觉噪声。
- B/C/D/F 只做了 +2000 平移，尚未按 10–12 分钟目标扩段。
