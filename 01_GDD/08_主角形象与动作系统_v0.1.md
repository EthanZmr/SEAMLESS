## 0. 一句话

**阿针不是“拿剑的赛博女侠”，是一个把战斗当维修的人：短、准、脏、省力。**
她的动作像干活——靠近、对准、下针、拉线、打结；阿绫接管时才突然变得“过量、过快、过亮”。

三条视觉支柱：

1. **剪影先于细节**：96px 高仍能认出“左义体 + 短外套 + 腰侧线轴 + 肩上一针红线”。
2. **动作是劳动，不是表演**：不转圈、不耍刀花；每一击都有明确的“对准—发力—收线”。
3. **双意识是同一具身体的不同电压**：阿绫不是第二个模型，是同一剪影的过载、色差、余像。

## 1. 阿针：外形定稿方向

### 1.1 基本信息

| 项 | 设定 |
|---|---|
| 年龄/身高 | 27 岁 / 约 1.70 m |
| 体型 | 偏瘦、肩背有力，长期弯腰干活，站姿微微前倾 |
| 身份 | 地下缝线师：修义体、补记忆、拆黑芯 |
| 轮廓关键词 | 短外套、左义体、腰侧双线轴、右手长针、左肩红线 |
| 禁区 | 不做成紧身战斗服、不露腰、不做“二次元女刺客”剪影 |

### 1.2 剪影优先级（从 96px 外轮廓读）

按重要度排序，任何一张正式图都必须保留：

1. **左前臂义体比右臂粗一圈**：二手工业义体，肘部有外露线缆，腕部一圈青色缝线光。
2. **短外套 + 高领**：衣长到腰，下摆不规整；高领在侧面形成一个小三角，和短发区分开。
3. **右腰两个线轴**：一大一小，像两个圆盘；跑动时会晃，是角色“会发出声音”的部分。
4. **右手长针**：约 28px（96px 角色基准），反手握，像握螺丝刀，不像握剑。
5. **左肩红线**：2px 宽，从领口下方斜向肩后；剧情锚点，始终可见。

> 96px 下，脸部细节全部放弃；靠发型轮廓、高领、义体和线轴认人。

### 1.3 比例（96px 游戏内）

|---|---|---|

### 1.4 服装与材质

- **外套**：深蓝黑防水工装，短款，高领，右袖卷到小臂；左袖直接拆掉，露出义体。
- **补丁**：外套上有 5–7 块不同颜色补丁，来自她救过的人；每块不超过 10px，远看是色块，不抢剪影。
- **内衬**：锈红/琥珀色，只在领口、下摆、动作翻起时露出；给冷色剪影一个暖色“伤口”。
- **裤子**：深灰工装裤，右腿绑一条工具带；膝盖有旧护膝。
- **鞋**：短靴，鞋底厚，雨天防滑；跑动时脚步重，不轻飘。
- **义体**：哑光枪灰，关节处露出旧线缆；不是亮银色，不反光到抢戏；腕部青色缝线是唯一发光点。
- **脸**：短黑发，左侧剃短（undercut），左眉一道旧疤；眼窝疲惫，不画浓妆；嘴角自然下垂，不笑时像在算账。
- **可选小道具**：领口挂一个磁性放大镜（loupe），只有特写用；96px 不画。

### 1.5 色板（阿针）

| 用途 | 色值 | 占比 |
|---|---|---|
| 外套/裤子主色 | `#1A2A3A` / `#101A26` | 60% |
| 义体/金属 | `#6C7A86` | 15% |
| 内衬/补丁暖色 | `#B4472F` / `#FFB13B` | 15% |
| 缝线/义体光 | `#3FE0D0` | 7% |
| 肩线/危险 | `#E5484D` | 3% |

规则：**红色只给肩线和接缝**；青色只给“可操作/可缝/义体光”；琥珀只给“人味/暖光/补丁”。

### 1.6 武器：缝针与线

- **针**：37px 长（128px 身高基准），针尖亮、针身暗；反手握，攻击时像“扎进去再拉出来”。
- **线**：从右腕/针尾出线，攻击轨迹是**短线 + 拉回**，不是大弧光。
- **线轴**：右腰两个圆盘，一个青线（可缝）、一个锈红线（承重/危险）；战斗中晃动，给剪影加“活物”感。
- **攻击语言**（定稿 v9：刺 → 拽 → 打结）：
  - 一段：平刺 + 拉线（针尖停住一帧，再收线；见 24 号规格）。
  - 二段：反手回拉，把线抽紧——命中后敌人被拽向阿针 14px（贴身时留 28px）。
  - 三段：把针扎进目标，双手拉线打结（重击、击退、最大 hit-stop）。
  - 挑空：针从下往上挑，像挑开线头。
  - 空中：平刺，接挑空连段（D17；下扎已砍，D19）。

## 2. 阿绫：同一剪影的“过载态”

### 2.1 出现原则

- 阿绫**没有独立身体**；不做漂浮少女、不做第二套模型。
- 默认：只在 HUD、台词、切换瞬间出现。
- 接管/高同步：阿针剪影外出现 **2–4px 偏移的故障重影**，颜色品红→紫，扫描线 + 噪点；不遮挡玩家视线中心。
- 低同步：噪点变少，颜色偏青白；阿绫“安静”时反而更可怕。

### 2.2 接管时的姿态变化（同一骨架）

| 部位 | 阿针 | 阿绫接管 |
|---|---|---|
| 头 | 微低，视线跟着针 | 微偏头，像在听什么 |
| 肩 | 收紧，护左肩 | 打开，动作更浪费 |
| 持针 | 反手、低 | 正手、像握笔/匕首 |
| 脚步 | 稳、短步 | 快、碎步、偶尔悬空半帧 |
| 收招 | 收线、回位 | 余像拖尾，不回位 |
| 颜色 | 青/琥珀 | 品红/紫 + 白芯 |

### 2.3 阿绫的战斗差异（切片内）

**不新增第二套招式**，用同一 3 段骨架做“电压差”：

- 攻速 +20%，伤害 +20%，完整度每秒 -2（沿用现有同步率规则）。
- 三段终结技变成 **过载打结**：同一判定框，多 2 次火花/电弧，hit-stop 更长，击退更远。
- 冲刺/受击/弹反带 1–2 帧余像；不新增无敌帧。
- 切换瞬间 0.15s 故障冲击波，打断杂兵轻击；冷却 0.4s（沿用规格）。
- 视觉：针线由青变品红，线轴转速加快，阿针剪影变暗、阿绫重影变亮。

> 这是范围控制：正式版若时间允许，再考虑阿绫独立第四段；切片不做。

## 3. 动作系统

### 3.1 核心循环（30 秒）

**看接缝 → 靠近（跑/爬/钩/冲刺）→ 弹反或起手 → 三段打结 → 切阿绫爆发 → 拉开/换位 → 下一个接缝。**

阿针负责“把局面变简单”，阿绫负责“把简单局面一次打穿”。切人不是换武器，是换节奏。

### 3.2 动词表（与当前代码对齐）

| 动词 | 输入 | 当前实现 | 动作设计 |
|---|---|---|---|
| 移动 | A/D | 220 px/s | 前倾、短步；急停有 2px 滑步 |
| 跳/二段 | Space | -600，二段 | 起跳压缩，二段空中翻身一小下 |
| 冲刺 | Shift | 560，全程无敌 | 低姿态、针收在身侧；不拖大残影；无敌改为只在第 4–9 帧（D19，待实现） |
| 轻击 | J | 3 段，10/12/20 | 刺—拉—打结；第三段最重 |
| 挑空 | S+J | 7 伤害/520 | 针从下往上挑，敌人浮空 |
| 空中攻击 | 空中 J | 9 | 平刺，接挑空连段（D17） |
| 弹反 | K | 0.08 完美/0.20 普通 | 针横持、线绷紧；完美时线亮白 |
| 换人 | L | 0.15s 冲击波 | 同一身体抖一下，阿绫重影弹出 |
| 钩索 | H | 320 范围/680 拉近 | 左手义体抬枪式，线从腕部射出 |
| 攀爬 | W | 132 | 左手先抓、右脚蹬；像修外墙 |
| 翻越 | 贴边 Space | 抓边/翻越 | 手撑、收腿、不翻跟头 |
| 缝 | U | 环境接缝 | 单膝跪、针穿线、拉紧 |
| 拆 | 待定 | 未实现（D19 采纳） | 弹反暴露接缝后撕开；精英/Boss 为处决演出，过程无敌、不可取消；零件/碎件由此获得 |

> D19（2026-10-23）砍掉、不进动词表：爬墙耗青线、墙上横跑、轻/重两档受击动画（只留一种受击，击退距离按攻击配）、空中下扎、招手。拾取只作零件安装演出的动画，不加按键。

> 表中数值是当前白盒值，不在本次设计中改动；正式动画必须按这些时序做，不先做“好看但对不上”的动作。

### 3.3 动作原则

1. **预备短**：攻击前摇不超过 6 帧（12fps 基准），靠针尖亮起和肩部收紧提示，不靠大抬手。
2. **命中帧清楚**：命中瞬间 1 帧“针停住”，然后才拉线；不要用模糊拖影代替命中。
3. **收招像收工具**：攻击结束把针收回腰侧/腕侧，不摆 ending pose。
4. **受击护左肩**：这是她的秘密位置；受击动画先缩左肩，再护头。
5. **跑动有重量**：脚步落地 2px 下沉，线轴晚 2 帧晃动；不飘。
6. **阿绫不换骨架**：只换节奏、姿态、颜色、余像；保证切换时玩家仍认得出“这是阿针的身体”。

### 3.4 动画状态机

```text
IDLE ──move──> RUN ──jump──> JUMP ──fall──> FALL ──land──> IDLE
  │                │             │
  │                └─dash──────> DASH
  │
  ├─J──> ATTACK1 ─> ATTACK2 ─> ATTACK3 ─> IDLE
  ├─S+J─> LAUNCHER ─> AIR_ATTACK ─> FALL
  ├─K──> PARRY_ACTIVE ─> PARRY_SUCCESS/FAIL ─> IDLE
  ├─L──> SWITCH (0.15s overlay, 不锁输入) ─> 原状态
  ├─W on climbable ─> CLIMB ─> CLIMB_JUMP/LEDGE
  ├─H on anchor ─> HOOK ─> HOOK_JUMP/LAND
  └─hurt──> HURT ─> IDLE/DEAD
```

- 当前代码状态：`IDLE/RUN/JUMP/FALL/DASH/ATTACK/PARRY/HURT/DEAD/CLIMB/WALL_SLIDE/LEDGE/HOOK`。
- 设计上不新增状态；`SWITCH` 是 0.15s 的视觉覆盖层，不阻断输入。
- 轻击 1/2 收招可被跳跃取消（命中后才开窗：一段 5–8f、二段 6–9f），动画必须给“收针→起跳”留 2 帧过渡，不能硬切；轻击 3 在击退段（13–17f）可取消，但取消不退 0.30s 冷却——取消买到的是机动，不是跳过代价。

基准：**12 fps 关键姿势，30fps 引擎播放**；白盒先做剪影，不追求最终帧数。

| 动作 | 关键姿势 | 循环 | 备注 |
|---|---:|---|---|
| Idle | 8 | 是 | 呼吸 + 线轴轻晃 |
| Run | 8 | 是 | 2 个触地帧 |
| Jump | 4 | 否 | 起跳压缩 |
| Fall | 4 | 是 | 外套下摆上扬 |
| Land | 3 | 否 | 2px 下沉 |
| Dash | 4 | 否 | 低姿态，1 帧拉长 |
| Climb | 6 | 是 | 左右手交替 |
| Wall slide | 2 | 是 | 脚蹬墙 |
| Ledge | 6 | 否 | 抓→撑→收腿 |
| Hook | 6 | 否 | 抬手→射線→拉近 |
| Attack1/2/3 | 6/6/9 | 否 | 第三段 2 帧命中停顿 |
| Launcher | 8 | 否 | 上挑 |
| Air attack | 5 | 否 | **平刺**（2026-10-22 定；下扎已砍，D19，见 `03_美术/27_` §4） |
| Parry | 5 | 否 | 横针、线绷紧 |

## 4. 动画资产方案

### 4.1 技术路线

**2D 剪影切件（cutout）+ 少量手绘特效**，不做全手绘逐帧。

- 角色高 96px，切件按 2x 制作（192px 高），导入后缩到 1x。
- 14 个切件：头、发、颈/领、躯干、外套前/后、左大臂、左义体前臂、右大臂、右前臂、左腿、右腿、左靴、右靴、腰/线轴。
- 针和线轴独立切件，方便做“针停住/线轴晚 2 帧”的次级动画。
- 阿绫重影不切件：用同一套切件 + shader（色差、扫描线、余像），避免双倍资产。
- 白盒阶段先用 `Polygon2D`/`Skeleton2D` 或纯代码方块验证时序；正式切件再替换。

### 4.2 命名与规格

| 类型 | 规格 |
|---|---|
| 切件 | PNG 透明底，2x，单件不超过 256×256 |
| 图集 | 2048×2048，单角色 |
| 锚点 | 脚底中心；针/线轴独立 pivot |
| 动画 | 12fps 关键姿势，30fps 播放；Godot AnimationPlayer |
| 命名 | `char_zhen_body_torso.png`、`char_zhen_arm_l_prosthetic.png`、`anim_zhen_attack_03.tres` |
| 颜色 | sRGB；切件不带背景光；发光走 shader/材质 |
| 授权 | 自绘/自制；如用生成图，登记模型+提示词；不混用来源不明素材 |

### 4.3 可读性验收

1. 纯黑、纯白、雨市霓虹三种背景下，96px 剪影都能认出。
2. 缩到 50% 仍能看出“左臂粗、腰侧圆盘、肩线”。
3. 阿绫接管时，0.2s 内能看出“换人了”，但不遮住敌人攻击。
4. 三段攻击的第三段，不看 HUD 也能从动作/停顿判断“这是重击”。
5. 所有闪烁 ≤3Hz；提供减弱闪烁/关闭色差选项。

## 6. 需要你拍板的三件事

1. **阿绫的可见度**：A. 只在切换/HUD/高同步出现（推荐，剪影清楚）；B. 平时也站在身后半步（更情感化，但容易挡视线/抢读）。
2. **技术路线**：A. 2D 切件 + 手绘特效（推荐，单人可维护）；B. 全手绘逐帧（更“手作”，但 105 帧会拖垮 32 周）；C. 像素风（与现有剪影/shader 方向冲突，不推荐）。
3. **针的持法**：A. 反手握、像工具（推荐，符合“干活”）；B. 正手握、像匕首（更攻击性，但容易变成通用刺客）。
