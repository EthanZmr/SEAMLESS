# 《无缝》角色与世界尺度约定 v1.0

> 2026-10-22。状态：**已定**（ADR-013）。
> 形象基准：`03_美术/参考/阿针_Apose_v4_用户生成.png`（`13_阿针角色形象锁定_v1.0.md`），约 2.5 头身。
> 本文回答一件事：**锁定形象画多大、放进现有世界后各种距离等于几个身位**。关卡（M2 起）与美术切件都以本文为准。

---

## 1. 结论

| 项 | 值 | 说明 |
|---|---|---|
| 世界单位 | 1 world px | 不变；所有已实现的移动/战斗参数、已摆关卡不改 |
| 碰撞体 | **28 × 56** | 不变（`scenes/player/player.tscn`） |
| 角色精灵世界高 | **64**（发顶 → 鞋底） | 1 身位 = 64 |
| 对齐 | 脚底 = 碰撞底；身体中轴（双脚中点）= 碰撞中线 | 碰撞顶在发顶下约 8px，蓬发不参与碰撞 |
| 相机基础缩放 | **2.0** | `game_camera.gd::base_zoom`；镜头冲击在此基础上按比例生效 |
| 屏幕显示高 | **128px**（1920×1080 内部分辨率） | = `03_美术/16_Q版赛博朋克风格规范` 的「游戏内显示高 128」 |
| 源稿 | 512px 高 | = 屏幕 4×、世界 8× |
| 可视范围 | **960 × 540** world | 原先 zoom 1 时是 1920 × 1080 |

为什么不放大碰撞体：碰撞 28×56 套在 64 高的 v4 剪影上正好盖住鞋底到发顶下方，宽度等于头发/肩宽（见 `06_测试/screenshots/SCALE_collision_fit_z2.png`）。放大碰撞体意味着跳跃、墙跳、钩索、取消窗口等全部手感参数与 A 区布局重调，而这些都已真人 GO。改相机缩放只改"看到多少"，不改"怎么动"。

为什么是 2.0：1.0 时角色在 1080p 里只有 64px 高，剪影识别点（左义体、红线、双轴、针）看不清；1.5 时 96px，是旧像素方案的尺寸，已被赛璐璐规格否掉；2.0 正好对上 128px 规格与 4× 源稿。三档对比见 `06_测试/screenshots/SCALE_zoom_1_1.5_2.png`。

## 3. 关卡设计尺寸（M2 起执行）

| 规则 | 值 | 依据 |
|---|---|---|
| 可站立通道最小净高 | ≥ 96（1.5 身位） | 碰撞 56 + 精灵 64 + 余量；低于 96 看起来像顶头 |
| 普通单跳台阶 | ≤ 110 | 一段跳 129 留 15% 余量 |
| 必须二段跳的台阶 | 130–210 | 233 留余量；超过 210 用攀爬/钩索 |
| 单跳可越缺口 | ≤ 160 | 189 留余量 |
| 二段跳缺口 | 190–270 | ≈306 留余量 |
| 墙跳井内宽 | 96–140 | 现 A3 井 96 可用 |
| 钩点相对玩家站位的竖直高差 | ≤ 260 | 可视半高 270，相机竖直偏移 −40；高差 320 会出屏 |
| 一屏内要能看到的东西 | 下一个落脚点、敌人前摇范围、钩点 | 可视 960 × 540；跑速 220 时前方约 2 秒 |
| 往下掉的路线 | 落点在起跳点下方 ≤ 230 内，或给下视提示 | 相机下半屏约 310 |

现有 A 区只做了三处截图检查（A1 屋顶、A3 墙跳井、A2 排水沟），zoom 2 下角色与周边结构都能读出；其余尺寸未逐条按上表复核，B/C 扩段时顺带检查。B/C 直接按本表在 `level_src/rain_market.tscn` 里摆。

## 4. 美术与其他角色

- 切件按 512px 源稿出，导入后精灵整体缩放到世界 64 高；`AttackSpec` 帧表与 ADR-012 不变，动画只跟随。
- 敌人沿用同一比例：精灵世界高 ≈ 碰撞高 × 64/56（清道夫 48 → 55，截线者 56 → 64，裁断者 110 → 126）。
- 阿绫不另做体型（ADR-005），同一精灵叠过载效果。

## 5. 待观察

- 可视范围从 1920 缩到 960 后，W6-01 的 3–4 分钟真人计时要在 zoom 2 下重新跑一次；路线读图、敌人发现距离可能变化。
- 若竖直方向的信息不够（往下跳、钩点在上方），优先调相机竖直偏移或加下视，不改尺度。
