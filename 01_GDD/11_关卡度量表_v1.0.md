## 1. 口径

- 1 身位 = 64（发顶 → 鞋底）；碰撞 28 × 56。
- 高度量**脚底**上升；缺口量两岸边沿之间的空隙（两岸同高，助跑）；台阶量贴墙起跳最后能站上去的高度。
- §2 是**理论上限**。摆关卡用 §3 的设计值，不直接用上限。
- 抓边对墙顶和薄台沿都有效（2026-10-23 修：原先厚度不到 26 的台沿抓不住）。台沿越薄，抓边够得越低：厚 ≥ 26 同墙顶，24 → 186，16 → 177。
- 抓住梯缝后会横向吸附到梯缝中线（2026-10-23 加，`CLIMB_SNAP_SPEED` 360 px/s，约 0.1 s 到位）；贴墙的梯缝停在墙边。
- 和 `09` 公式值不同的原因：起跳那一帧不吃重力，单跳实测 134（公式 129）；缺口实测包含碰撞体宽度（起跳时最多探出边沿 14 px，落地时最多差 14 px 也能站住）。

## 3. 摆关卡用的设计值

规则：**主路 ≤ 上限 × 85%**；**能力锁 ≥ 前面所有阶段上限 × 115%**。两者之间是"要技巧"区，只放可选奖励，不放主路。

| 用途 | 台阶高 | 缺口宽 |
|---|---|---|
| 开局主路 | ≤ 112 | ≤ 180 |
| 锁 ①（开局上不去） | ≥ 153 | —（见下 1） |
| ① 后主路（靠抓边） | ≤ 157（台沿厚 ≥ 24；厚 16 时 ≤ 150） | ≤ 200 |
| 锁 ⑤（① 加抓边也过不去） | ≥ 215 | ≥ 272 |
| ⑤ 后主路（顶点二段） | ≤ 197；带抓边 ≤ 243 | ≤ 281 |
| ⑤ 后可选（晚按二段、冲刺组合） | — | 282–405 |
| 墙跳井（④） | 内宽 96–240 | — |
| 钩点（③） | 落脚平台高出钩点 ≤ 60；⑤ 后 ≤ 146 | 钩点竖直高差 ≤ 260（`09` §3，镜头） |

### 实测带出来的设计约束

1. **缺口锁不住 ①**：开局过不去的缺口（≥ 246）① 也过不去（上限 236）。① 只能用绿色梯缝锁，不能用缺口锁。
2. **台阶锁 ① 的窗口只有 153–157**，太窄；台沿厚 16 时没有窗口（主路 ≤ 150 < 锁 153）。建议 ① 一律用梯缝锁。
3. **缺口锁 ⑤ 的窗口是 272–281**（按顶点二段算），偏窄。要么按"快落回时二段"算主路（窗口变成 272–323，但要教玩家晚按），要么把 ⑤ 的锁做成台阶或竖井。
4. **④ 之后，两面墙相距 ≤ 288 的竖向空间都能爬上去**。不想被 ④ 爬上去的地方，对面墙要隔 ≥ 320。单面高墙 ④ 爬不上去。
5. **有 ④ 时，贴墙在空中按跳 = 墙跳，不是二段**（代码里墙跳优先），会被推离墙面。要求二段跳上的高台，前面要留起跳距离，别让玩家只能贴墙起跳。
6. 钩点按"最近"选：两个钩点都在 320 内时钩近的那个，摆钩点时别让错的那个更近。
