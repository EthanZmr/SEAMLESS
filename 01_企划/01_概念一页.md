# 《无缝》概念一页

## 一句话

2147 年，垂直巨城。缝线师阿针靠修义体、补记忆为生；她脑子里住着另一个人的意识——无缝集团首席架构师白露的妹妹。集团要把旧城全部回收，重建成一座没有接缝的完美城市；阿针要决定：把脑子里的声音还回去，还是留着它，继续做一个拼起来的人。

## 设计支柱

1. **战斗**：双意识切换，一控场一爆发；弹反＝接住敌人的接缝；切得越狠越爽，但同步率会反噬。
2. **故事**：你脑子里的声音，是你必须杀死的人；你的身体，是别人妹妹的补丁。
3. **关卡**：城市是一台可拆、可黑、可缝的机器；接缝既是路，也是锁。
4. **视觉**：维修朋克；白城无影、无缝、无菌——越干净越恐怖。

## 玩家每 30 秒在做什么

扫描接缝 → 神经针钉住 → 沿光纤突进 → 拆义体核心 → 缝敌人/改线路 → 切阿绫爆发 → 同步率反噬 → 找下一个接缝。

## 双意识

- **阿针**：控场、修复、稳。纤维可缝敌人、缝自己、造桥。
- **阿绫**：爆发、故障、玻璃大炮。过载、短路、闪现；持续掉完整度、涨同步率。
- **同步率 0–100**：阿针降、阿绫升。满 100 阿绫强制接管 8 秒；到 0 阿针稳定缓回。玩家在跷跷板上跳舞。
- **弹反＝接缝**：独立弹反键；完美弹反自动换人反击，同步冻结，接缝暴露；可弹环境接缝，把 Boss 的“剪断”变成你的“缝合”。

## 差异化

赛博朋克是红海，但“双意识切换 + 弹反接缝 + 维修朋克”是三个可验证的差异点。卖点不是霓虹，是**“修”与“拆”的同一性**：你为了活下去拆别人，为了记住他们把他们缝在身上。

## 叙事基调

阿针与阿绫是共生关系，不命名、不贴标签；可以读成姐妹、共生伴侣、或同一个人分裂出的两个声音。暧昧停留在情绪、共感与身体反应，不做露骨描写。M 级用于暴力与身体恐怖，不用于性。

## 切片范围

序章「诊所」8–10 分钟 + 第一关「雨市」20–25 分钟 + Boss「裁断者」5–8 分钟。3 种杂兵、1 个 Boss、2 个补丁二选一、1 个关键选择、1 个悬念结尾。

**不做**：第 2–6 章、4 个 Boss、七块记忆补丁、完整技能树、三结局、NG+、配音、主机、多人。

## 成功标准

1. 玩家 2 分钟内能解释同步率。
2. 第一场战斗主动切一次阿绫。
3. 不用提示拆接缝改变战场至少一次。
4. 打完裁断者能复述“她脑子里是她姐的妹妹”。
5. Boss 3–5 分钟，普通玩家 ≤3 次过。
6. 中端 PC 60fps。
