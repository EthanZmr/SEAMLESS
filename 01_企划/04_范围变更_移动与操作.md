# 范围变更评估：完整攀爬与操作扩展

- 日期：2026-10-19
- 触发：W2 试玩反馈“只有跳跃/加速，没有攀爬；地图只有几个跳台；Boss 一次过”
- 用户决策：要**完整攀爬**，并且“操作不止攀爬，要更丰富”
- 当前基线：单人、Godot 4.7.2、PC、3 个月切片《序章 + 雨市 + 裁断者》35–45 分钟；W1 白盒完成，剩余约 10 周

## 1. 变更内容

不是加一个“攀爬键”，而是把主角从“跑跳 + 单段攻击”升级成一套**移动/战斗动词组**：

### 移动（建议 4 个）
- 完整攀爬：可攀表面（管道、电缆、建筑接缝）上下移动；攀爬跳；放手
- 抓边/翻越：空中抓边，Space 翻上，S 放手
- 墙跳/墙滑：从墙面或攀爬状态蹬墙，打开竖向路线
- 缝线钩（signature）：瞄准锚点，收线拉近；不做完整钟摆物理，先做“拉近 + 可拉敌人”

### 战斗（建议新增 3 个，不是 10 个）
- 地面 3 段轻击（J-J-J），末段可击退
- 空中攻击（空中 J）
- 挑空/下砸二选一（先做挑空，服务空连）
- 保留：弹反 K、换人 L、缝 U、冲刺 Shift

设计原则：**不加按键数量，加“同一按键在不同情境的结果”**。例如 Space = 跳 / 攀爬跳 / 墙跳 / 翻越；J = 地面连段 / 空中攻击。

## 2. 成本估算（单人，含返工缓冲）

| 模块 | 估算 | 说明 |
|---|---:|---|
| 完整攀爬 + 墙跳 + 抓边 | 15–20 天 | 状态机、碰撞、4–6 套动画、关卡可攀标记 |
| 缝线钩 | 7–10 天 | 瞄准、锚点、拉近、相机、可拉敌人 |
| 战斗扩展 | 10–15 天 | 3 段连击、空中攻击、挑空、命中反馈、敌人受击 |
| 雨市垂直重排 + Boss 改造 | 10–15 天 | A–F 加三层、危险、追击；Boss 加垂直/钩索应对 |
| 美术/音频/UI/试玩/构建 | 15–20 天 | 新动作剪影、特效、音效占位、3 人试玩 |
| **合计** | **57–80 天** | 约 12–16 周；当前只剩 10 周 |

结论：**完整攀爬 + 丰富战斗 + 原 35–45 分钟内容 + 3 个月，四项不能同时成立。**

## 3. 三个选项

### A. 4 个月“深切片”（推荐）
- 周期：总周期 16–18 周（净增 4–6 周）
- 内容：完整攀爬 + 抓边 + 墙跳 + 缝线钩 + 3 段地面连击 + 空中攻击 + 挑空
- 关卡：雨市 A–F 保留，重排为三层垂直路线；时长 25–30 分钟
- 砍：盾卫、第三接缝、第二补丁、1 个重复遭遇；不砍 Boss/序章/结局
- 风险：缝线钩与攀爬的关卡需求可能互相打架；先做 3 天原型，不好玩就退回抓边
- 适合：你要的是“操作手感与表达”，不是内容长度

### B. 3 个月“窄切片”
- 周期：12 周（不延期）
- 内容：完整攀爬 + 抓边 + 墙跳 + 2 段连击 + 空中攻击；**不做缝线钩**
- 关卡：砍到 A–C + Boss，约 20 分钟；D–F 降 S1
- 风险：内容量不足，Boss 前铺垫变短；仍然很紧
- 适合：必须守住 3 个月，可以接受切片变短

### C. 3 个月“原计划 + 抓边”
- 周期：12 周
- 内容：只加抓边翻越 + 无人机 + Boss 调压；不做完整攀爬
- 这不是你刚提出的需求，仅作为保底方案

## 4. 推荐与门禁

推荐 **A**：4 个月，25–30 分钟深切片。理由是完整攀爬和战斗扩展都需要关卡与 Boss 重新围绕它们设计；如果只加动作不重排关卡，最后还是“几个跳台”。

先做 **3 天攀爬原型**（B 雨市入口 90 秒）：
- 通过：能连续攀爬/墙跳/抓边完成一段 30 秒竖向路线，且不别扭
- 不通过：退回抓边，重新评估是否值得 4 个月
