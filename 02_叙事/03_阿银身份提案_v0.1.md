> 现有 canon：阿针、阿绫、白露；没有阿银。

## 1. 先分清三个人

### 阿针（A-Zhen）
- 27 岁，地下缝线师。
- 身体是阿绫意识的容器；左肩红线是白露缝的。
- 主题：**缝、修、扛**。

### 阿绫（A-Ling）
- 17 岁（永远 17），白露的妹妹，织网病晚期。
- **没有身体**；意识备份在阿针脑内，是阿针的故障 overlay。
- 主题：**声音、记忆、接管**。
- 她不是阿银；不要给她一个白发实体，否则“脑内声音”这个前提就废了。

### 阿银（A-Yin，工作名）
- 目前没有 canon。
- 如果保留这个名字，建议她是**白露的测量师/裁剪师**，不是阿针的姐妹，也不是阿绫的实体。

---

## 2. 推荐关系：镜像对手，不是家人

**阿银 = 白露的测量师/裁剪师，白城“无缝”标准的执行者。**

- 她负责测量旧城的身体、建筑、记忆，判断哪些“不合规”，哪些需要被回收/重做。
- 她相信“没有缝=没有痛”，是白露理念的人形化身；不是恶毒反派，是**真诚地认为自己在救人**。
- 她与阿针的关系是**镜像**：
  - 阿针缝人，阿银量人；
  - 阿针用针，阿银用尺/剪；
  - 阿针在雨里修，阿银在白塔里判；
  - 阿针的身体有缝，阿银的衣服没有缝。
- 她不是阿针的姐妹，也不是阿绫；她**不知道阿绫在阿针脑内**。
- 与白露：她是白露的助手/门生，是白露“可以修好的那个版本”；阿绫是白露“修不好的妹妹”。这构成白露的三角，但阿银自己不知道。

### 剧情功能
- 白城第一次“礼貌地”进入雨市：不拿刀，拿尺。
- 她给阿针量身体，发现“37 处不合规”；她真心建议阿针“来白城，重新做”。
- 她越礼貌，越恐怖；她不是来杀阿针，是来**纠正**她。
- 后期她发现阿绫的存在，动摇的是她“无缝=正确”的世界观，而不是她的善恶。

### 不推荐的关系
- **阿银 = 阿绫的实体**：破坏“阿绫没有身体”的核心。
- **阿银 = 阿针的亲姐妹**：家庭戏会挤掉“身体/意识”的主线。
- **阿银 = 白露的另一个妹妹**：重复阿绫，且让白露的动机变散。
- **阿银 = 白阿针/换色**：没有独立角色价值。

## 3. 形象区别：黑针 vs 白尺

| 维度 | 阿针 | 阿银（推荐版） |
|---|---|---|
| 身份 | 地下缝线师/修理工 | 白城测量师/裁剪师 |
| 轮廓 | 短、横、前倾、左重右轻 | 高、直、对称、纵向 |
| 头发 | 黑色、乱、左侧剃短、短深色发夹 | 银白、高马尾、一丝不乱、无发夹 |
| 脸 | 左眉疤、疲惫、黑眼圈、不化妆 | 无疤、平静、白城式“无瑕”；可有一道**测量墨线**（不是伤口） |
| 手臂 | **左前臂二手工业义体** | **双臂原生**，白手套/精密手套；不做机械臂 |
| 肩 | 左肩红线，8–10 针 | 无红线；肩线干净、无缝 |
| 服装 | 短工装、补丁、工具带、旧靴 | 象牙白长外套、高领、无可见缝线、剪裁精确、白靴/软底鞋 |
| 颜色 | 黑/炭、锈红、青、红线 | 象牙白、冷灰、淡青；**不用红** |
| 工具 | 25cm 针、右腰双线轴、青线 | 软尺、粉笔、长裁缝剪、顶针；**没有线轴** |
| 姿态 | 低、蹲、干活 | 直、站、量 |
| 96px 识别 | 黑团 + 红肩线 + 灰左臂 + 双线轴 | 白色竖线 + 高马尾 + 长外套 + 剪刀/软尺 |
| 战斗语气 | 缝、拉、打结 | 量、裁、压 |

### 阿银的视觉禁忌
- 不要白发版阿针：同脸、同姿势、同机械臂、只换色。
- 不要巨大剪刀当剑；她的剪是**裁缝剪**，精确、短、冷。
- 不要红色点缀；红色是阿针的“底”，阿银用白/灰/淡青。
- 不要暴露/护士/女仆化；她是**白城官员**，不是服务角色。
- 不要长裙拖地；她需要走路、测量、下蹲，衣服要利落。

## 4. 阿绫怎么画

- 没有身体；平时是阿针的**故障 overlay**：半透明、色差、噪点、偶尔浮出少女轮廓。
- 颜色：品红/青，随情绪变化；开心偏暖，生气偏红。
- 17 岁，但不是实体；不要给她白发、白大衣、剪刀。
- 如果剧情需要“看见阿绫”，那是**记忆投影/接管瞬间**，不是阿银。

---

## 5. 关系一句话

- **阿针 × 阿绫**：一具身体，两个意识；不命名，互相保护，也互相怕。
- **阿针 × 阿银**：一个缝人，一个量人；镜像对手，不是家人。
- **阿银 × 白露**：门生/助手；白露“能修好的版本”。
- **阿银 × 阿绫**：互不知道；阿银是白露失去阿绫后的替代，阿绫是阿银不敢问的真相。
