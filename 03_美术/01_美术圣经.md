# 《无缝》美术圣经

> 版本：v0.1（切片）
> **v0.2 方向修订（2026-10-21）**：游戏内改为**手绘赛璐璐（hand-drawn cel）**，不是像素风。角色显示高改为 **128 px**（源稿 4x，512 px），96 px 仅保留为剪影压力测试，不再作为生产规格。详细规范见 `03_美术/16_赛璐璐风格规范_v0.1.md`。
> 风格一句话：**维修朋克（Repair-Punk）——一座被缝起来的霓虹巨城，白城不是未来，是洗白后的过去。**

---

## 1. 视觉总纲

| 维度 | 旧城·缝线城 | 白城·无缝集团 |
|---|---|---|
| 关键词 | 补丁、接缝、油污、雨、霓虹、拥挤 | 无缝、白、镜面、静音、尺度、空 |
| 形状 | 碎、歪、手工、不对称 | 整、直、模数化、压迫 |
| 颜色 | 青蓝底 + 品红/琥珀霓虹 + 锈红 | 冷白 + 浅灰 + 一条品牌青 |
| 材质 | 湿沥青、旧塑料、焊痕、胶带、布 | 陶瓷、玻璃、拉丝金属、无影灯 |
| 镜头 | 手持感、低机位、遮挡多 | 固定、俯视、对称、无遮挡 |
| 声音（视觉化） | 滴水、电流、叫卖 | 白噪、空调、脚步回声 |

**核心反差**：旧城“脏但活”，白城“净但空”。不要用“赛博朋克=紫+青+霓虹雨”的默认模板；霓虹只出现在**人做生意、人活着**的地方。

## 2. 色板

| 用途 | 色值 | 说明 |
|---|---|---|
| 底色·夜 | `#0B1220` | 雨夜蓝黑，不用纯黑 |
| 底色·湿 | `#132235` | 沥青反光 |
| 霓虹·青 | `#3FE0D0` | 医疗/缝线/UI 主色 |
| 霓虹·品红 | `#FF3E8A` | 市集/广告/危险提示 |
| 霓虹·琥珀 | `#FFB13B` | 面摊/暖光/记忆 |
| 锈红 | `#B4472F` | 旧城结构/血/断口 |
| 骨白 | `#F2EFE6` | 白城/义体/裁断者 |
| 品牌青 | `#1FB6C9` | 无缝集团标识 |
| 阿绫故障 | `#FF5C7A` → `#7A5CFF` | 色差/噪点/情绪 |

**用色规则**：
- 每个场景最多 2 个主霓虹 + 1 个暖色锚点；白城场景只用骨白 + 品牌青 + 一点冷灰。
- 红色只给“危险/接缝/血/裁断”，不要当装饰。
- UI 颜色与场景分离：HUD 用青白，危险用锈红，阿绫用故障品红。

## 3. 角色设计

### 阿针
- **剪影**：短外套 + 大工具包 + 左手义体略大；走路微微前倾，像随时要蹲下修东西。
- **细节**：外套补丁每块颜色不同，来自不同人；左肩红线是剧情锚点，始终可见；针线轴挂在腰右侧，战斗中会晃。
- **动画语言**：动作经济，不摆姿势；攻击像“干活”，不是“耍帅”；受击先护左肩。
- **尺寸**：游戏内显示高约 **128 px**（1080p 基准）；源稿 512 px（4x）手绘线稿，导入后降采样。96 px 只用于剪影压力测试，不是正式尺寸。

### 阿绫（overlay）
- **形态**：不是实体；半透明轮廓 + 色差 + 扫描线 + 噪点；情绪越强，噪点越密。
- **颜色**：平静=青白；开心=琥珀；生气/接管=品红→紫；同步率>70 时边缘出现“烧灼”白边。
- **出现位置**：阿针身后半步，或屏幕边缘；从不遮挡玩家视线中心。
- **禁止**：不做成“漂浮的二次元少女”；她是信号，不是幽灵。

### 白露
- **剪影**：极简白色长风衣/无褶套装；没有多余配件；头发一丝不乱；身高比阿针高半头。
- **细节**：衣服没有缝线；唯一“缝”是左胸一枚极小的品牌青胸针；鞋底不沾水。
- **动画**：动作少、慢、准；不挥手，不指人；说话时身体不动，只有头微偏。
- **对比**：她越安静，越可怕。

### 裁断者
- **剪影**：白色外骨骼 + 巨剪；肩宽、腿细、头小；像一把立起来的尺。
- **细节**：外骨骼上有“量尺”刻度；头盔面甲是条形码；关节处露出旧缝线（暗示她也是补丁）。
- **动画**：机械、节拍化；攻击前有“量”的动作（抬剪、对齐、停顿）；三阶段逐渐出现人的迟疑。
- **尺寸**：高约 160 px，剪展开约 220 px。

### 敌人
- **清道夫**：白城外包，白色护甲 + 青色目镜；动作整齐，像流水线。
- **清扫无人机**：圆盘 + 单眼 + 吸盘；飞得低，爱贴墙。
- **水蛭**：从接缝里爬出的黑色线虫；无眼，靠震动找人。
- **共同语言**：白城的敌人都“干净、对称、无个性”；旧城的敌人（如果有）要“脏、歪、有生活痕迹”。

## 4. 环境

### 诊所（序章）
- 10×6 m 的单间；手术灯、货架、旧沙发、鱼缸（养的不是鱼，是发光菌）；墙上贴满欠条。
- 光源：手术灯冷白 + 鱼缸青 + 窗外霓虹品红；三个方向的光打架。
- 可交互：骑手手臂、工具台、药柜、门、窗、记忆补丁。

### 雨市（第一关）
- **A 后巷**：宽 8-12 m；两侧雨棚、空调外机、晾衣绳；地面反光；出口被清道夫堵住。
- **B 入口**：垂直 3 层；巨型招牌用红色承重缝吊着；人群、面摊、小贩；招牌是“白氏义体”旧广告。
- **C 霓虹巷**：宽 6-8 m；湿地导电；霓虹招牌低垂；电力接缝在脚下；可电敌。
- **D 磁轨站**：长 60-80 m；磁轨每 6 s 过一班车；站台边缘有黄色警示线；纤维锚点在头顶。
- **E 交易所**：室内 12×8 m；货架像果酱架；老猫柜台；后门通广场。
- **F 裁断广场**：圆形直径 30 m；补丁板地面；四根承重缝吊着；白城投影广告在头顶循环。

**环境叙事规则**：
- 每个场景至少 1 个“有人在生活”的细节（晾衣、面摊、神龛、欠条、小孩涂鸦）。
- 每个场景至少 1 个“白城在量你”的细节（刻度、白线、二维码、广播、回收车）。
- 接缝必须可见、可读：红色=承重/危险；青色=可缝/可拉；品红=白城/裁断。

## 5. UI

- **HUD**：左上完整度（不用血条，用“缝线”长度 + 断口数量）；下方同步率（一条会抖的线，不是百分比数字）；右下纤维轴上膛数；交互提示用“针”图标。
- **字体**：OFL 授权，标题用几何无衬线（如 Orbitron/Chakra Petch 类），正文用高可读黑体（如 Noto Sans SC）；中文必须嵌入子集，避免缺字。
- **对话框**：半透明黑底 + 青色细边；阿绫台词用故障色、轻微抖动；不遮挡战斗中心。
- **菜单**：旧城风格=补丁拼贴；白城风格=纯白留白；设置里必须有“高对比/色盲/减弱闪烁/字幕大小”。
- **图标**：针、线轴、剪刀、接缝、补丁；统一 2 px 描边，青白配色。

## 6. VFX

| 效果 | 做法 | 时长/参数 |
|---|---|---|
| 缝线 | Line2D + 噪点 shader；两端有“针孔” | 0.2-0.4 s |
| 断线 | 线断成 3-5 段，带重力 | 0.5 s |
| 弹反火花 | 白→青→品红三层粒子 + 全屏 0.03 s 白闪 | 0.12 s |
| 完美弹反 | 时间减速 0.08 s + 接缝高亮 + 阿绫色差爆发 | 0.2 s |
| 接管 | 屏幕边缘故障、色差、扫描线；阿针剪影变暗 | 0.6 s 进/出 |
| 雨 | GPU 粒子 + 地面涟漪贴图；不遮角色 | 持续 |
| 霓虹闪烁 | 材质 emission 随机脉冲；不要全屏频闪 | 0.1-0.3 s |
| 血/机油 | 风格化：锈红/黑油，粒子 + 地面贴花；不喷溅 | 0.3 s |

**无障碍**：所有闪烁不超过 3 Hz；提供“减弱闪烁/关闭色差/高对比”选项；危险提示不只靠颜色，加形状/图标。

## 7. 资产规格

| 类型 | 规格 |
|---|---|
| 基准分辨率 | 1920×1080；2D 引擎单位 1 px = 1 单位（仅碰撞/布局用，不是像素画网格） |
| 角色源稿 | 单帧 512×512 PNG（4x），显示高 128 px；图集 4096×4096；线稿/平涂/阴影分层 |
| 环境 | 手绘模块 512/1024 px；TileSet 32 px 仅作碰撞/布局，不显示网格；背景 1920×1080 分层 |
| UI | 9-slice；图标 64×64/128×128；细线、硬边、少发光；字体子集 |
| 动画 | 12 fps 关键姿势，30 fps 运行时；手绘关键帧 + 切件 puppet；关键帧命名 `zhen_run_00` 等 |
| 上色 | 赛璐璐：平涂 + 2–3 阶硬边阴影 + 1 阶高光；不用软笔刷厚涂/照片纹理 |
| 线 | 深棕黑 `#1A1210`；源稿 3–4 px，显示 1–1.5 px；外轮廓粗于内线 |
| 命名 | `char_zhen_run_00.png`、`env_rainmarket_sign_a.png`、`ui_sync_bar.png` |
| 授权 | 每份资产登记来源/授权/作者；AI 生成标注模型+提示词；字体必须 OFL/Apache |

## 8. 参考与禁区

**参考**：*Katana ZERO* 的霓虹与节奏；*Ghostrunner* 的白城尺度；*Blade Runner 2049* 的雾与巨构；*Signalis* 的低保真身体恐怖；*Hollow Knight* 的剪影可读性；*Celeste* 的关卡模块化。

**禁区**：
- 不做像素风；游戏内是手绘赛璐璐，不是 pixel art。
- 不做“紫青霓虹雨+日文招牌”的模板赛博朋克。
- 不做写实血腥特写；M 级靠氛围和后果，不靠猎奇。
- 不做“白城=纯坏”的扁平设计；白城要美、要干净、要让人一瞬间想留下。
- 不做不可读的剪影；角色在纯黑背景上必须能认出。
- 不使用来源不明的素材/字体/音乐。
