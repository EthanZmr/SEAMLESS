# 角色概念图评审 v0.1

> 评审对象：用户提供的两张 2048×2048 角色概念图（阿针 / 阿银）。
> 用途：判断“能不能直接进游戏”，以及下一步改什么。
> 结论先说：**立绘很好，但不能直接当 96px 游戏 sprite；两张目前更像同一角色的双色版本，而不是两个独立角色。**

---

## 1. 先看优点（这些要保留）

1. **针/线/剪刀的视觉系统成立**：阿针的针+线轴，阿银的剪刀+线，线把两人连在同一张图里；“缝 vs 裁”的对立一眼能看懂。
2. **黑/白镜像构图有叙事感**：一个旧城维修工，一个白城裁缝/量体师；如果这是有意的对照，方向很强。
3. **头发剪影有记忆点**：阿针的乱短发 + 发夹，阿银的长白 hair；在钥匙孔/对话头像里能认人。
4. **表情有性格**：阿针是“别烦我，我在干活”；阿银是“我在量你”。不是通用笑脸。
5. **服装层次丰富**：外套、束带、工具挂件、线轴，能撑起“维修朋克”的世界观。

## 2. 96px 可读性测试

见 [03_角色96px比例测试.png](<03_角色96px比例测试.png>)。

| 尺寸 | 阿针 | 阿银 |
|---|---|---|
| 320px | 细节完整，能看清发夹、缝线、线轴 | 细节完整，能看清剪刀、衣褶 |
| 96px | 头发/外套/针线还在，但脸和胸衣细节消失 | 白发/白外套/剪刀还在，但整体偏白团 |
| 64px | 只剩“黑发+深色外套+一点线” | 只剩“白发+白外套+剪刀” |
| 48px | 基本是一团黑 | 基本是一团白 |

**判断**：
- 96px 仍能认出“两个人”，但认不出“谁是谁的细节”；48px 只靠颜色区分。
- 阿针的黑衣+黑发在雨市暗底上会糊；阿银的白衣+白发在白城/霓虹亮底上会糊。
- 如果直接缩成 sprite，**发夹、胸衣扣、毛领、耳坠、缝线纹理全部白做**。

## 3. 与现有设定的冲突

### 3.1 阿针

| 现有设定 | 图里 | 影响 |
|---|---|---|
| 左前臂二手义体，比右臂粗 | 两臂看起来都是有机/手套，没有明显义体 | 丢掉最重要的剪影识别点 |
| 左肩一针红线 | 未见 | 丢掉剧情锚点（白露缝的那一针） |
| 工装外套缝满补丁、油污 | 毛领、束胸、金属扣、干净黑金 | 更像“哥特裁缝/贵族刺客”，不像地下维修工 |
| 27 岁、疲惫 | 脸偏幼，chibi 比例 | 立绘可以风格化，但 M 级故事里会显得年龄不对 |
| 针 28px、反手握 | 针很长、线很飘 | 动作读起来像“魔法针”，不像工具 |

**不是画得不好，是“角色定位”偏了**：图里是“黑暗系缝纫师”，文档里是“雨里修义体的劳动女性”。两者可以合并，但必须选一个主方向。

### 3.2 阿银

| 问题 | 说明 |
|---|---|
| 她是谁？ | 现有角色表里没有“阿银”。她是阿绫的实体化？白露的另一个作品？白城版阿针？还是新角色？ |
| 剪刀的语义 | 剪刀在《无缝》里属于**裁断者/白露的“裁”**；如果阿银是正面角色，会抢反派的视觉语言；如果她是白城/反派，那就非常成立。 |
| 和阿针太像 | 同一张脸、同一姿势、同一发夹、同一外套剪裁，只换了颜色和武器；像 palette swap，不像两个独立角色。 |
| 白色过曝 | 白发+白外套+白鞋，在亮背景会糊；需要深色内搭/青色描边/一块品牌青。 |
| 无缝 vs 有缝 | 白城的美学是“没有缝”；她的白外套却有明显缝线。若她是白城人，这是有意的“破例”还是矛盾？需要剧情解释。 |

## 4. 三种处理方案

### 方案 A：立绘保留，游戏内另做简化切件（推荐）

- 这两张作为**对话头像 / 角色图鉴 / 商店页 / 概念图**，不直接进平台跳跃。
- 游戏内按 96px 重新做 14 件切件：保留大头发、外套下摆、针/线轴；删毛领/胸衣/细扣；补左义体、肩红线、补丁。
- 代价：需要再画一套 sprite；但这是唯一能同时保住“图好看”和“游戏能读”的路。
- 适合当前 32 周、单人、2D 切件管线。

### 方案 B：全面转向 chibi 像素风

- 把游戏内分辨率降到 640×360 或 480×270，角色 48–64px，世界、敌人、UI 全部重做像素风。
- 代价：现有 1920×1080 白盒、霓虹 shader、瓦片/背景全部要改；32 周内风险极高。
- 只有在“你就想要这个像素 chibi 游戏”时才选。

### 方案 C：保留故事，改立绘

- 保留“雨里维修工”的设定，把毛领/束胸/黑金改成短工装、补丁、油污、左义体、红线。
- 代价：这两张图要重画；但游戏内 sprite 和立绘能统一。
- 适合“世界观优先于单张图”的选择。

> 我推荐 **A + 对阿针做 C 的局部修正**：立绘走“黑金哥特裁缝”也可以，但游戏内 sprite 必须是“左义体+短外套+线轴+红线”的维修工；两者用同一套颜色和发型连接。

## 5. 如果保留这两张，下一步怎么改

### 阿针（优先级从高到低）

1. **加左前臂义体**：比右臂粗一圈，腕部青色缝线；这是第一识别点。
2. **加左肩红线**：2px，从领口斜向肩后；不要当装饰，受击动画要护它。
3. **减掉毛领/束胸/多余金属扣**：换成工具挂带、补丁、油污；保留一件“她救过的人”的补丁。
4. **把针加粗到 28px**：反手握，针尖亮、针身暗；线从针尾/腕部出，不要飘全身。
5. **把脸从“幼”调到“疲惫的 27 岁”**：不是画老，是去掉婴儿肥、加重眼下阴影；保留短发/疤。
6. **颜色**：黑蓝外套 + 锈红/琥珀补丁 + 青色义体光；金色只做小面积工具，不做主色。

### 阿银（先回答她是谁）

- 如果她是**白城/裁断者阵营**：保留白+青，剪刀加大；外套改成“无褶、无缝”的整块面料，只有左胸一枚品牌青胸针；和阿针的补丁形成对照。
- 如果她是**阿绫的实体化**：不建议。阿绫的核心是“没有身体”，给她身体会拆掉故事支点；而且剪刀是裁断者的语言。
- 如果她是**新角色/对手**：把姿势、脸型、发型、外套剪裁拉开；不要和阿针同姿势镜像；可以让她“量”阿针，而不是“对称站立”。
- 如果她是**可操作第二角色**：范围警告——第二套动作/动画至少 +80–120h，32 周内不建议；先做 NPC/对手。

## 8. 结论

**图是好的，且“针线 vs 剪刀”的双人对照很有潜力；但它们现在是“角色立绘”，不是“游戏角色”。**

下一步不是继续加细节，而是先定：
- 阿银的身份；
- 立绘与 sprite 的关系；
- 阿针是“哥特裁缝”还是“维修工”。

这三个定完，我再做 96px 切件测试；否则会把一张不能动的图当成能跑的角色。
