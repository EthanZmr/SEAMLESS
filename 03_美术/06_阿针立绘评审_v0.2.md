# 阿针立绘评审 v0.2

> 对象：用户提供的 2560×1440 三联立绘（正面 / 近景 / 背面）。
> 结论：**作为主视觉/宣发立绘，很强；作为游戏内角色，不能直接用；作为多视图设定，左右侧有硬伤。**

---

## 1. 总评

| 维度 | 分数 | 说明 |
|---|---:|---|
| 角色叙事 | 9/10 | “雨里的修理工”终于成立了：脏、旧、工具、义体、红线都在。 |
| 主视觉吸引力 | 8.5/10 | 雨市氛围、湿发、机械臂、针线关系都抓人；可以直接做 Steam 胶囊/头图方向。 |
| 与现有 2D 管线匹配 | 4/10 | 照片级 3D 渲染，不是 2D 切件；不能直接进当前 Godot 白盒。 |
| 多视图一致性 | 6/10 | 正面/近景的义体在角色左臂，背视图翻到了右臂；发夹/红线也跟着翻。 |
| 可做 96px sprite | 5/10 | 大形够，但机械臂/红线/线轴在 96px 会糊；需要重新做切件。 |

**一句话**：这是一张很好的“阿针是谁”的图，不是一张“阿针怎么动”的图。

## 2. 已经对了的地方（保留）

1. **脸龄对了**：27 岁左右，疲惫、警惕，不是小孩。
2. **左前臂义体**出现了，且是“皮肉接金属”的接缝，不是整条银臂。
3. **左肩红线**在近景可见，位置对（锁骨到肩）。
4. **右腰两个线轴**（青/锈红）在正面和背面都在，颜色对。
5. **针+青线**的关系对：针是工具尺寸，线从手/腕走，不是魔法杖。
6. **服装终于像维修工**：无袖/短外套、补丁、工具带、旧靴；毛领/束胸/大面积金饰没了。
7. **雨市氛围**：湿沥青、霓虹 bokeh、雨线、暖摊灯，和 A–C 的视觉方向一致。

---

## 3. 必须修的问题

### 3.1 左右侧翻转（最严重）

- 正面/近景：机械臂在**角色左臂**（画面右），正确。
- 背视图：机械臂在**画面右**；背对观众时画面右 = 角色右臂，**翻了**。
- 同样翻的还有：左肩红线、左侧发夹、针线手。
- 这会让建模/切件/动画参考全部对不上；如果这是 AI 三联图，典型的多视图漂移。

**修法**：以“角色左臂 = 机械臂、左肩 = 红线、左侧发夹”为唯一契约；背视图必须镜像回来。不要用这张直接做三视图。

### 3.2 义体太“新”、太像护甲

- 现在是小臂银灰壳 + 红色线缆，像 cosplay 护腕/高级义体。
- 设定是**二手工业义体**：应该有不对型号的板件、外露活塞、油泥、旧焊点、皮肉接缝处的红/肿；至少一处“修过”的痕迹。
- 手部结构也要检查：AI 容易把手指/关节画成装饰。

### 3.3 脸太“拍摄”、不够“干活”

- 皮肤太干净、唇色/眼线太完整；像雨里拍美妆大片。
- 需要：黑眼圈、毛孔/油光、雨水/油污、被雨打湿的碎发贴在脸上；不是变丑，是“她刚干完活”。
- 近景很美，但和“地下诊所、通宵修义体”的生活感有距离。

### 3.4 针线的物理逻辑

- 近景里青线从手腕绕到针，但**没有明确连到腰上的线轴**；线像悬浮特效。
- 建议：线从右腰线轴 → 手腕导线环 → 针尾，三段可见；不要全身乱飘。
- 针尖/针眼结构要清楚；现在针更像细长锥子。

### 3.5 发夹/针形发饰过多

- 左侧发夹像一把短针/天线，剪影很酷，但 96px 会变成乱刺；也容易和“针”武器混淆。
- 保留 2–3 根就够；其中一根可以是“她自己的针”。

### 3.6 疤痕位置

- 近景疤痕在**右颊/鼻梁**（画面左），设定写的是**左眉**。
- 不是大问题，但要做成 canon：选一个，写进角色卡，之后所有图统一。

### 3.7 三联图不是“三视图”

- 三个面板的姿势、光、焦距不同，背面还转身；不能当 orthographic turnaround 用。
- 作为宣发三联/角色介绍很好；作为建模/切件参考，需要另做**同光、同姿势、正/侧/背**的 turnaround。

---

## 4. 这张图应该怎么用

### 推荐：主视觉 + 游戏内简化切件

- 这张作为 **Steam 胶囊、商店页、对话近景、角色图鉴** 的方向图。
- 游戏内另做 96px 切件：保留大头发、短外套、左义体、两个线轴、肩红线；删发夹/细补丁/皮带扣；把义体做成**高对比青色关节光**，不然 96px 看不清。
- 立绘与 sprite 用同一套颜色和剪影，不要求同一细节量。

### 不推荐：直接缩成 sprite

- 96px 下机械臂会变成灰袖子，红线会消失，线轴会变成两个点；玩家只能看到“黑发+灰臂”。
- 这张的细节是给近景/宣发的，不是给平台跳跃的。

### 如果要做 3D/照片级游戏

- 那是另一条管线：建模、绑定、动画、光照、渲染，32 周单人不可行；当前 Godot 2D 白盒不应按这个方向走。

---

## 5. 下一步（按优先级）

1. **先修左右侧一致性**：背视图机械臂/红线/发夹镜像回角色左；不然越画越错。
2. **再做一张真正的 96px 切件测试**：只保留 6 个识别点，纯黑/纯白/霓虹底各看一次。
3. **义体加“二手感”**：不对型号板件、外露活塞、油泥、焊点；不要整条银壳。
4. **脸加生活感**：黑眼圈、油光、雨湿碎发；少一点唇妆/眼线。
5. **针线接回线轴**：线轴→腕环→针尾，三段可读。
6. **定疤痕 canon**：左眉还是右颊，写进角色卡。
7. **记录资产来源**：模型/提示词/seed/后期；这张若是 AI，登记模型与版本。

---

## 6. 结论

**这张阿针立绘，作为“她是谁”的答案，已经成立；作为“她怎么在游戏里跑跳打”的答案，还不成立。**

我会把它定为 **Key Art v0.2 / 宣发与近景方向**，不直接进游戏；下一步做 96px 切件测试，并把背视图的左右侧翻修正。这样既保住这张图的气质，又不会把一张不能动的图当成能跑的角色。

### 进步

- 正面/近景：机械臂在**角色左臂**，肩红线在左肩，发夹在左侧；这一版终于前后一致（仅正面/近景）。
- 无袖外套 + 工具带 + 补丁，比 v0.2 更像维修工，少了一点“护甲感”。
- 脸部/身体有更多雨水和污渍，年龄感更稳。
- 双线轴、义体接缝、红线在 320px 都能读。

### 仍未解决

1. **背视图还是翻的**：机械臂在画面右；背对观众时画面右 = 角色右臂，应为画面左。肩红线和发夹也一起翻了；双线轴反而没翻（角色右臀 = 画面右）。这不是整张镜像，是局部漂移，必须逐项修。
2. **脸还是太干净**：皮肤、唇色、眼线仍像美妆大片；需要黑眼圈、油光、雨湿碎发，不是变丑。
3. **义体还是太“新”**：银色壳 + 红线缆，缺少不对型号板件、外露活塞、旧焊点、油泥。
4. **针线没有接回线轴**：近景里青线从针到手，但没有清楚的“线轴→腕环→针尾”三段。
5. **疤痕位置**：仍在右颊/鼻梁，设定写左眉；要定 canon。
6. **96px**：只剩“黑发 + 深衣 + 灰臂 + 一点青”；64px 以下成团，仍然需要另做切件。

### v0.3 评分

- 主视觉：**8.8/10**
- 游戏内 96px 资产：**4/10**
- 多视图一致性：**5.5/10**（正面/近景 8，背视图 4）

### 结论

**v0.3 可以锁为 Key Art v0.3，但不能锁为角色三视图。**  
下一步只做两件事：先修背视图的左右侧，再做 96px 简化切件；不要继续在照片级细节上加码。
