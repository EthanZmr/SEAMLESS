## 1. 锁定优先级

1. **v4 A-pose（本文件）**：角色设定的第一参考。侧别、剪影、服装、义体、工具以它为准。
2. **v2.0 照片级**：宣传/主视觉渲染参考；如果和 v4 冲突，以 v4 为准。
3. **v3 蹲姿 chibi**：角色选择/剧情 CG 姿态参考，不作为切件基准。

## 2. 锁定的识别点

| 部位 | 锁定要求 |
|---|---|
| 脸 | 左眉一道缝线旧疤（画面右）；成年脸；疲惫、不卖萌 |
| 头发 | 黑色、顶部乱、左侧剃短（画面右）；2–3 根短深色发夹 |
| 义体 | 左前臂+左手（画面右），肘下开始；二手工业件 |
| 红线 | 左肩（画面右），8–10 针；与义体同侧，不要求覆盖肘下接缝 |
| 线轴 | 右腰（画面左）两个：青 + 红；红轴不穿针 |
| 针 | 右手（画面左）反握；青线；针眼/线尾关系要清楚 |
| 服装 | 短高领工装、左肩裸露、右袖/臂带、补丁、工具带、旧工靴 |
| 剪影 | 黑发团 + 左灰臂 + 左肩红线 + 右腰双线轴 + 右针青线 |

## 3. 已接受的非硬伤（不再改）

- **年龄表现偏 18–22**：chibi 风格化接受；主视觉/3D 仍按 27 岁处理。
- **针偏长**：作为 chibi 夸张接受；96px 切件可缩短 20–30% 以免读成矛。
- **狗牌**：锁定图保留；设定上作为某个病人的遗物，非每张图必须出现。
- **红线偏新**：立绘接受；游戏内切件用旧线/低饱和。
- **风格为平滑 chibi，不是像素**：96px 需另做切件，不直接缩图。

## 4. 变更控制

- 不再为“更像/更帅/更细”重新生成角色大形。
- 只有以下情况允许解锁：
  1. 96px 三背景测试无法认出 5 个识别点；
  2. 动画切件发现肢体/工具结构不可拆；
  3. 剧情新增硬设定（例如义体范围改变）。
- 解锁必须记录原因、影响文件、旧图归档；不允许静默覆盖。
