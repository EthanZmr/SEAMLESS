## 1. 一句话

**Q 版大头（约 2.5 头身）的雨夜赛博朋克：深色工装 + 义体金属 + 霓虹轮廓光；剪影先于细节。**

## 2. 规格

| 项 | 规格 | 备注 |
|---|---|---|
| 基准分辨率 | 1920×1080 | 16:9；UI 单独适配 |
| 阿针游戏内显示高 | **128 px** | = 世界高 64 × 相机缩放 2.0；碰撞 28×56 不变（`09`） |
| 源稿 | 512 px 高 / 帧（4x） | 透明底；PSD/KRA 分层源文件保留 |
| 比例 | 约 2.5 头身 | 与锁定形象 v4 一致 |
| 视角 | **玩法状态一律侧视** | 跑、跳、攻击、弹反、受击、爬墙等在游戏里能切换的状态必须同一视角；正面/四分之三只用于演出与 UI |
| 帧数标注 | **一律 60 fps 逻辑帧**（或直接写秒） | 与代码帧表 `AttackSpec`（FPS = 60）一致；关键姿势数量另行说明，不混用 12/30 fps 帧号 |
| 运行时 | 按帧表时长播放 | 判定、取消窗、顿帧以帧表为准，动画只跟随（ADR-012） |
| 交付 | 单帧透明 PNG + 图集 | 锚点 = 脚底中心；针/线轴独立 pivot；图集 4096×4096/角色 |

## 3. 可读性（128 px 下必须成立）

1. **不要大面积纯黑**：头发、背心、裤子、靴子用偏亮的深灰褐（明度 ≥ 20%），给轮廓留出层次。
2. **霓虹轮廓光**：主色青 `#3FE0D0`，阿绫/接管时品红 `#FF3E8A`。引擎侧用描边/轮廓光 shader 统一加（2 px 级），美术不必每帧画；美术源稿里的边缘高光作为补充。
3. **细节为剪影让路**：裤子破洞纹理、外套碎边、头发碎丝在 128 px 会变成噪点，出单帧时概括处理；保留识别点——左眉疤、左臂义体、腰侧双线轴、针、左肩红线。
4. **帧间一致**：头发外形、外套下摆等大形逐帧锁定，只在动作需要时变化；避免每帧重画导致的"抖"。
5. 验收：128 px 下放在纯黑、纯白、雨市夜景三种背景上，能一眼读出剪影、朝向和识别点。

## 4. 动画与制作路线

- **默认全部逐帧单张图**（2026-10-23，D21）：512px 源稿、透明底、脚底中心锚点，张数按 `01_GDD/08` §3.5，播放按 60fps 帧表停帧。
- 切件补间只作退路：第 4 层先做 8 张跑步循环试点；帧间一致或工时不达标时，只把跑、爬、钩改成切件补间。攻击/受击/弹反/接管始终逐帧。
- 阿绫不另画身体：复用阿针的帧，叠色差/故障/品红轮廓光（参考换人 SWITCH 分解图）；不做姿态差异帧、不做独立半身像（D21）。
- 补间只用于位移和轻微形变，不用于线条变形。

## 5. 环境与 UI

- 环境手绘分层：远景巨构 / 中景楼体 / 近景摊位 / 雨幕；TileSet 只做碰撞与布局。
- 霓虹是光源，用 emission/bloom，不全屏频闪。
- UI 硬边、细线；青/品红与场景同色板。

## 6. 与 Key Art 的关系

- Key Art（记忆投影、接管瞬间）是宣发/剧情全屏图，可以更插画化、更高细节。
- 游戏内单帧保留识别点，不保留 Key Art 的所有细节；不要把 Key Art 直接缩成游戏帧。
