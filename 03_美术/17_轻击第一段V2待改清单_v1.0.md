## 0. 结论

V2 的「4f 起手 → 命中 → 收招」骨架方向是对的，画面对节奏的读感也清楚。但它有 **3 类问题**：

1. **标注硬伤 6 处**——已在 V3 帧表修正，不要回退（见 §1）。
2. **结构性比例错误 1 处 + 规格不匹配 2 处**——V3 没修，**会影响可玩性**（§2 P0-1～P0-3）。
3. **动作语言/契约缺失 4 处**——缺「拉线」、缺事件帧表、缺 whiff 分支、缺脚位说明（§2 P0-4～P0-7）。

另有两个设计规则需要你拍板（§3），以及一串文档债务（§4）。

**一句话**：这张图现在能当「动作讨论稿」用，还不能当「生产帧表」用。要先解决「参照物比主角矮」这件事，否则整招的刺击高度、针长、判定盒会三头不对。

## 2. 必改（V2 仍在，V3 也未解决）

### P0-1 参照物比例反了：假人比主角高，游戏里敌人比主角矮

| 项 | V2 图（换算到 128px 基准） | 游戏内规格 | 差 |
|---|---|---|---|
| 阿针身高 | 图内 410px = **128px** | 128px（16 §2） | ✅ |
| 参照假人 | 图内 450px = **140px** | 清道夫 **96px** / 截线者 **112px**（资产清单） | **高 25%–46%** |
| 针刺出高度（地面到针尖） | 图内 250px = **78px** | 96px 敌人胸口 ≈ **58px** | **高 20px** |

- 后果：按 V2 的姿势做 128px 正稿，针会从清道夫**头顶/肩上**掠过；判定 `abs(dy) ≤ 62` 仍能打中（敌人中心在 48px），但玩家会看到「戳空气掉血」。
- 根因：V2 把敌人当「标准成人」画（假人 1.1 倍主角），但本作是 chibi 主角打更矮的杂兵。
- 改法（选一）：
  - **A（推荐）**：参照物换成 96px 清道夫 + 112px 截线者两张，针刺点下移到敌人胸口 ≈ 55–60px；主角姿势从「高位平刺」改为「微屈膝 + 髋部前送」的平刺。
  - B：把清道夫放大到 128px、截线者 140px——要改所有敌人碰撞体与关卡尺度，**不推荐**。
- 验收：在 128px 正稿上叠 96px 敌人，针尖与敌人胸口重叠、不超头顶。

### P0-2 针画短了一半，84px 判定比视觉长 26px（空气刀）

| 项 | V2 图（128px 基准） | 规格/代码 | 结论 |
|---|---|---|---|
| 针长 | 图内 50–60px = **15–19px** | 08 §1.3：28px @96px → **37px @128px** | **短约 50%** |
| 针尖到脚底中心（5f） | 图内 185px = **58px** | `COMBO_RANGE[0] = 84px` | **判定长 26px（+45%）** |
| V3 提示词写的针长 | 「约半个头高」= **25px** | 同上是 37px | 也偏短 12px |

- 后果：判定 84px 是「从 origin 向前 84px」的矩形（`player.gd:565-570`），视觉针尖只到 58px → 有 26px（约 1/5 身高）的无形判定，玩家会读成「没碰到就掉血」。
- 改法（选一）：
  - **A（推荐）**：针加长到 **37px**（512 源稿 148px）。手臂 ≈ 40px + 针 37px + 前倾 ≈ 8px → 视觉针尖 ≈ 85px，与 84px 判定基本吻合，不用改代码。
  - B：判定缩到 62–66px，同时接受「贴脸打」的手感，并重调 `COMBO_RANGE` 与敌人 `attack_range` 的相对关系。
- 顺带：V3 提示词、08 §1.3、资产清单的「针」尺寸三处要统一成同一个数。

### P0-3 受击硬直 6f（100ms）≠ 代码 0.18s（180ms）

- V2：HIT REACT **6f = 100ms**。
- 代码：敌人 `take_hit()` → `stagger(0.18)`（`sweeper.gd:146`）= **180ms ≈ 11f**。
- 后果：动画 100ms 回正，逻辑还要再僵 80ms——玩家会看到「敌人已经站好了却不动」，这是可感知的卡顿；反过来若按动画改逻辑，敌人 100ms 就恢复，玩家 200ms 的收招还没完。
- 建议：受击面板改为 **0f / 3f（8° 峰值）/ 11f（回正）**，与 0.18s 对齐；如果坚持 6f，就要把 `stagger(0.18)` 一起改，并在 W5 打击感测试里复测。
- 注：击退 6–8px 是对的——`COMBO_KNOCKBACK[0] = 120`，stagger 期间 `move_toward(velocity.x, 0, 900·delta)`，位移 = 120²/(2×900) = **8px** ✅。

### P0-4 缺「拉线」：角色核心动作语言没画出来

- 08 §3.2 定义轻击是 **「刺—拉—打结」**；V2 是「刺（5–6f）→ 命中（7f）→ 拔针（8f）→ 收招」，**没有「拉」**。
- 08 §3.3 原则 2：「命中瞬间 1 帧『针停住』，然后才拉线；不要用模糊拖影代替命中」。V2 在 7f 命中后 1 帧就拔针，**直接违背**。
- V3 已补 F3「拉线·定格」（青线绷直、线轴震）✅，但 V2 的 8f 仍写「收回 拔针」，需要改成「停针 → 拉线 → 拔针」三步，否则动画师会照 V2 做。
- 验收：不看特效，只看剪影也能读出「针进去—线绷紧—针拔出」三个节拍。

### P0-5 缺事件帧表（这张图最大的「规格缺口」）

V2 只标了判定，没标这些必须由动画触发的系统事件。V3 的「事件/判定」列也只写了判定。需要补：

| 事件 | 触发帧 | 值（代码 SOT） |
|---|---|---|
| 判定开 | 0.060s（F2 内） | `ATTACK_ACTIVE/COMBO_ACTIVE[0] = 0.06`，单次扫描 |
| hit-stop | 命中瞬间 | 75ms / `Engine.time_scale = 0.06`（**不是 0，是 6% 慢放**） |
| 同步率 | 命中 | 阿针形态 **-2**（`GameState.add_sync(-2.0)`） |
| HitSpark | 命中 | 尺寸 **30px**，色 `#FFE6A8`，位置 = 敌人位置上移 26px |
| 相机 | 命中 | `_shake(5 + 1×3) = 8`；轻击 **无 punch**（只有 combo3 有 0.055） |
| 接缝 | 命中 | **不暴露**（只有完美弹反 `on_parried(true)` 才 `seam_timer = 1.5`） |
| 输入缓冲 | hit-stop 期间 | `InputBuffer.add_age_grace(75ms)` 补偿，按键不丢 |
| 跳取消 | 0.060s 起 | 见 §3 D1——**空挥也能取消** |
| SFX | 命中/空挥 | 命中金属高频 + 低频；空挥有收针声，二者要分开 |

- 另外：`HitStop._input()` 在冻结期间按跳会**立即 skip() 提前解冻**（`hit_stop.gd:35-40`）。这条也要写进帧表，否则没人知道「命中后立刻按跳会吃掉 hit-stop」。

### P0-6 判定是「单帧扫描」，不是 V2 承诺的持续窗口

- 代码：`attack_hit_done` 保证 `_do_attack_hit()` **每次挥击只执行一次**，时刻 `attack_timer ≤ attack_time - attack_active`（= 0.06s）。
- V2：active 标 2f（33.3ms）或 4f（66.7ms）的持续窗口。
- 差异：如果 60ms 那一帧敌人不在范围、66ms 时才进入，**不会补判**。对 84px 长判定影响小（敌速 100px/s 时 6.7ms 只移动 0.7px），但契约必须写清。
- 建议：帧表写「单帧扫描 @0.060s」；若要做刺击的扫掠判定，改 Area2D 或 active 窗口内每帧扫描，并同步改测试。

### P0-7 「双脚位置不动」与图面矛盾

- V2 注：「双脚位置不动」，但五格脚位明显在变（并立 → 前跨 → 大跨 → 后撤 → 收拢）。
- 代码：ATTACK 状态受 `FRICTION 2200`，`velocity.x = 35` 在 0.016s 内归零，**实际位移 0.28px**——物理上确实是原地。
- 结论：不是「脚不能动」，而是「root 不动、脚可换步」。建议写成：**「脚掌允许 8–12px 换步；root 位移 ≤1px」**，并让 V3 提示词从「双脚固定」改为「脚位可换步、root 锁定」。否则动画师会为了「脚不动」把前倾做成穿模。

## 3. 需要你拍板的设计规则（不是图的错）

### D1 跳取消：空挥也有效，轻击零惩罚

- 代码 `player.gd:290`：`can_cancel = attack_hit_done or attack_timer ≤ attack_time - attack_active` → **0.06s 后无论是否命中都能跳取消**。
- 现状：轻击 1 可以「出针→立刻跳走」，recovery 4 帧纯装饰，空挥无风险。
- 选项：
  - **A 保持**：轻击=位移/起手工具，代价是伤害低（10）+ 同步 -2。适合高机动 rushdown。
  - **B 改 hit confirm**：只有命中后才能跳取消/接第二段。空挥必须吃完 0.20s。更有博弈，但连段会变「黏」。
- 影响面：改 B 会动 `player.gd` 的 can_cancel 条件 + 现有 89 条移动测试，需要复测。

### D2 连段是「排队」，不是 V2 说的「9f 取消」

- 代码：攻击中按 J → `combo_queued` → **等 0.20s 结束**才启动第二段（`player.gd:471-473`）；排队窗口 0.16s。
- V2 写「第 9 帧起可接第二段」，读起来像 9f 就切第二段动作。实际 9f 按下去要等到 12f 才出。
- 选项：
  - **A 保持排队**：改动小，但连段有 3 帧「按了没反应」的空窗。
  - **B 做真正 early cancel**（9f 起切第二段）：连段总时长从 0.72s 缩到约 0.60s，节奏更紧，但要改状态机 + 补测试。

### D3 敌人 origin 未定义

- 代码判定用 `enemy.global_position` 当中心；白盒敌人 origin 在碰撞体中心（Sweeper 48px 高，中心在 24px）。
- 美术规范只写了「阿针锚点脚底中心」，**敌人锚点没写**。96px 敌人若锚点脚底，中心在 48px；若锚点中心，中心在 0。
- 需要拍板：**所有角色（含敌人、Boss）统一 origin = 脚底中心**；否则攻击判定高度会随美术导入方式漂移。
