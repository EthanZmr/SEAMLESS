## 2. P0 硬伤（不改无法进入逐帧贴图）

### P0-1 三套比例尺互不一致（本版最大问题）

实测（2048×1152 原图）：

| 比例来源 | 84px 在图上应画多长 | 隐含比例尺（图内px/游戏px） |
|---|---|---|
| 右侧身高标尺图（0→132px = 371px） | 236px | **2.81** |
| 主画面角色（标称 132px，实测高 300–360px） | 197–229px | **2.27–2.73** |
| 距离标尺（图上实际 0→84px = 300px） | 300px | **3.57** |

最长 3.57 与最短 2.27 差 **57%**。且距离标尺三个刻度不成比例：
- 0→84（84 游戏px）：300 图内px
- 84→96（12 游戏px）：160 图内px（应为 43）
- 96→132（36 游戏px）：360 图内px（应为 129）

**标尺是等距装饰，不是比例尺。** 修法：全图统一 `1 游戏px = 2.35 图内px`（2048 宽 @ 132px 角色），所有标尺、针、判定框、假人按同一比例重画；距离标尺刻度按 84 → 197px、96 → 226px、132 → 310px 摆放。

### P0-2 身高基准 132px 与规范冲突

`16_赛璐璐风格规范_v0.1.md:22` 明确「阿针游戏内显示高 **128 px**，不是 96px」。132px 会让针长（37→38.5）、判定、敌人比例连锁错位。**改回 128px**，或先走 ADR 改规范再改图。

### P0-3 假人仍高于主角（上一轮 P0-1 未修）

主画面假人实测 365 图内px ÷ 2.35 = **155px 游戏**，比主角 132px 高 18%。
而游戏内清道夫 **96px**、截线者 **112px**，都比主角矮 12.5–25%。**参照物方向反了**，导致"针尖到哪算够到"整张图都没有依据。
修法：主画面假人画 **96px**（= 226 图内px），另加一个 112px 的截线者轮廓做上限参照。

### P0-4 7f 命中与代码 0.06s 差 3 帧

- 图：7f = 0.100–0.1167s 命中。
- 代码：`COMBO_ACTIVE[0] = 0.06`（`player.gd:31`），active 在攻击开始后 **0.06s = 第 4 帧**触发，且 `attack_hit_done` 只判一次（`player.gd:567`）。
- 代码结构实际是 **3.6f startup / 1 帧判定 / 8.4f recovery**，图是 **4f / 4f / 4f**。

二选一（强烈建议先拍板再动手）：
- **A（推荐）**：改图。帧带改为 1–3f startup、4f HIT、5–12f recovery；判定仍 0.06s。理由：轻击要"脆"，改代码会连带影响三段连击节奏。
- **B**：改代码。`COMBO_ACTIVE[0]` 改 0.10，判定改 5–8f 持续窗口。代价：前摇 4f→6f，手感变钝，且三段都要重调。

### P0-5 hit-stop 50ms 是旧值（已回退）

`player.gd:599-601` 是 `[0.075, 0.105, 0.160]`，轻击 1 = **75ms**。上一轮 V3 帧表已改为 75ms，这版回退成 50ms。改回 75ms。

### P0-6「无击退硬直」与代码、与本图右侧面板三处矛盾

- 事件帧 7f：「无击退硬直、血条 -1」
- 右侧面板：「HIT REACT 6f / push 6–8px」
- 代码：`sweeper.gd:146` `stagger(0.18)` = **180ms 硬直**，且 `player.gd:573` 施加 **120px/s 击退**（位移 8px 与图一致）

三者只能留一个。建议改成：「180ms 硬直 + 8px 击退 + 血条 -1」，并删掉"无击退硬直"。

### P0-7 8f「定格判定尾」姿势却是收手

8f 是 hit-stop 冻结帧，姿势必须与 7f 完全一致（最多 1px 呼吸）。本版 8f 手臂已收回胸前，**同时假人身上还留着命中火花**——视觉上"人收手了、火花还在打"。
修法：8f 复用 7f 原图（freeze），或直接删掉 8f 格，把"定格"画在 7f 右侧的 hit-stop 色条里。

### P0-8 5f 已是满伸展，缺「刺出过程」

5f 与 7f 针尖长度相同，5f→7f 只有躯干前倾，没有针的位移。active 第一帧就满姿 = 视觉瞬移 79px。
修法：5f 画半伸（针尖 ~40px）、6f 到位（79px）；或 5f 后加 1 帧 smear（针+速度线，长度 30–50px，透明度 60%）。

## 4. P2（画面与缺失）

1. 主画面 5 格角色 x 逐格右移（约 180/370/620/900/1180），读起来像"角色在前进"，与"root motion 0 / 双脚不动"矛盾。应固定角色基准线，或加"每格独立取景、世界坐标不变"说明。
2. 距离标尺 0 点（x≈350）与第 1 格角色脚底（x≈180）不对齐。
3. 网格是 10 图内px（≈4 游戏px），几乎没有参考价值。改 32 游戏px 主网格 + 8px 细网格。
4. 缺 smear/速度线规格（5f→7f 针的位移轨迹）。
5. 缺青线（线轴→针眼）三态：刺出绷直 / 命中绷紧 / 收回松垂。这是角色识别点，不能只有针。
6. 缺 sync/接缝事件：命中 `add_sync(-2.0)`、轻击 1 是否暴露接缝，未标。
7. 缺 12f→idle 的 2f 交叉过渡（13f 直接切会跳）。
8. damage 10 未标敌人血量（清道夫 40 = 4 格），建议写"10/40 = 1 格"。
