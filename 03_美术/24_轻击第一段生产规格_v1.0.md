# 轻击第一段「刺—拉—钉」生产规格 v1.0

> 状态：**设计已定稿（V8）→ 本文件为生产 SOT**
> 替代：`17~23` 六份评审文档只作历史记录，不再作为依据
> 代码 SOT：`05_游戏工程/scripts/combat/attack_spec.gd`、`scripts/player/player.gd`（ATTACK 分支）
> 测试：`tests/test_attack_spec.gd`（24 条）、`tests/test_light1_behavior.tscn`（7 条）
> 基准：角色 Sprite 画布 128×128 游戏 px，身体视觉高约 124
> 时间基准：60fps 逻辑帧；动画 12 帧 = 0.200s；hit-stop 75ms 计在 4f 内

## 1. 帧表（唯一权威）

| 帧 | 区间 | 关键姿势 | 判定/事件 | 真实时刻 |
|---|---|---|---|---|
| 1f | 0–16.7ms | 重心下沉：后脚重心压低、腰胯下沉、肩与针不动 | — | 0–16.7ms |
| 2f | 16.7–33.3ms | 转肩蓄力：上身微转向假人、针随肩转动、仍朝下朝后 | — | 16.7–33.3ms |
| 3f | 33.3–50ms | 前倾预备：躯干前倾、针尖抬起对准假人肩部、反握（掌心朝上） | — | 33.3–50ms |
| 4f | 50–141.7ms | **HIT 命中**：针尖停在胸口、硬边白闪、青线绷直；假人后仰 8°、被推 6–8px | 判定帧 0.060s（单帧 flag）；hit-stop 75ms | 50–141.7ms（含冻结 91.7ms） |
| 5f | 141.7–158.3ms | 定格尾：角色保持 4f 姿势、白闪消散、青线松弛、**不收手** | 跳取消窗开启（5f） | 141.7–158.3ms |
| 6–12f | 158.3–200ms | 收招：6f 起收手、7 帧收 79px（约 11.3px/帧）、手腕内翻、12f 回正 | 9f 起连段输入窗 | 158.3–200ms |

### 1.1 smear（叠加层，不占时间轴）

- 4f 起帧挂残影：针尖半透明拉长 6–8px、沿刺出方向拖出，additive，Δt=0，12f 内淡出
- 只挂在 4f 起帧，**不占独立帧、不占时间轴**
- 工程实现：`Sprite2D` 叠加层或 `Line2D`，由 `_spawn_smear()` 钩子触发（尚未实现，见 §7）

### 1.2 时间账

| 口径 | 数值 |
|---|---|
| 动画 | 12f = 0.200s |
| hit-stop | 75ms（4f 内，真实时间冻结） |
| 4f 名义时长 | 16.7ms |
| 4f 实际时长 | 91.7ms（16.7 + 75） |
| 4f 真实区间 | 50–141.7ms |
| 5f 起点 | 141.7ms |
| 真实感知总长 | 275ms |

## 2. 判定几何

| 参数 | 值 | 说明 |
|---|---|---|
| 水平 | 0 至 84px | 从角色脚底中心 origin 向前；84 = `COMBO_RANGE[0]` |
| 垂直 | ±62px | `abs(offset.y) <= 62`；覆盖假人从脚到肩 |
| 形状 | 84×62 矩形 | 不是水平线，不是"全身高都打" |
| 判定时机 | 0.060s 单次扫描 | `attack_hit_done` 只保证执行一次，不代表命中 |
| 命中判定对象 | 敌人 `global_position` 中心点 | 非 hurtbox 边缘；宽体敌人需另议（§7） |
| 有效中心距 | 70–98px | 84 ± 14（假人 hurtbox 半宽 14） |

**针尖与判定**：针尖伸出 79px = 42（前伸，含前倾 12–16）+ 37（针身）。判定边缘 84px 比针尖多 5px，即 5px 余量。

## 3. 取消规则（V8 定稿）

| 输入 | 条件 | 结果 |
|---|---|---|
| 跳 | **命中后**、第 5–8f、在地面 | 取消攻击 → 跳（`_cancel_attack_into_jump`） |
| 跳 | 空挥 / 4f 内 / 9f 后 | 不取消；输入被吞掉，不缓冲到收招后 |
| 攻击（连段） | **命中后**、第 9f 起 | 排队，0.200s 结束后启动第二段 |
| 攻击（连段） | 空挥 / 9f 前 | 不排队；输入被吞掉 |
| — | 空挥（未命中任何敌人） | 不可跳、不可连段，走完 12f；`attack_cd` 在结束时置 0.30s |

**判定与取消的分离**：`attack_hit_done` = 判定帧已执行；`attack_hit_landed` = 真的打到了敌人。取消窗只看后者。这是 V8 落地时发现的必须拆分（原代码只用一个 flag，会导致空挥也能取消）。

## 5. 美术制作要求

### 5.1 交付物

| 编号 | 内容 | 规格 |
|---|---|---|
| A1 | 6 张关键帧姿势 | 512×512 源稿，4x 安全边，透明底 |
| A2 | smear 叠加层 | 与 A1 同画布，单独图层/文件 |
| A3 | 受击反应 3 格（命中前 / 后仰 8° / 回摆） | 参照假人用，不进游戏 |
| A4 | 时间轴标注图 | 标注每帧区间、事件、判定框（84×62） |

### 5.2 每帧要点

1. **1f**：肩与针不动，只有重心下沉——避免"起手就挥"的预告不足
2. **2f**：转肩带动针后收，针仍朝下朝后；**不要提前露出针尖**
3. **3f**：躯干前倾 12–16px，针尖抬到假人肩高；反握（掌心朝上）
4. **4f**：针尖停在假人胸口，**不加长光刃、不穿过身体**；白闪 + 青线绷直 + 假人后仰
5. **5f**：保持 4f 姿势，只让白闪消散、青线松弛；**手不收**
6. **6–12f**：6f 起收手，7 帧收 79px；青线在 6–7f 回缠线轴；12f 回正

### 5.3 禁用

- 长光刃当命中特效（违背"针停住 1 帧"原则）
- 4f 针尖穿过假人身体
- 用模糊拖影代替命中定格
- 在 5f 收手（会造成 1 帧跳变）
