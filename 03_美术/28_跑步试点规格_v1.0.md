> 2026-10-23。D18 角色定稿第 4 层第一步；D21 技术路线的试点门禁（`01_GDD/08` §4.1、§5 P1）。

> 姿势参考：`阿针 · 跑 RUN 逐帧分解 v3（触地脚压线修正）.png`（8 个关键姿势）；比例与识别点：`13` 锁定、`16` §2/§3、`27` §3。

## 1. 试点要回答什么

1. 用现在的出图方式做逐帧，能不能做到**帧间一致**、**128 px 可读**？

## 3. 画布、比例与锚点

| 项 | 值 | 说明 |
|---|---|---|
| 画布 | **768 × 576 px**，8 张完全相同 | 跑姿比站姿宽，针拖在身后，512 宽放不下 |
| 比例尺 | 与 `assets/characters/azhen_v4_placeholder.png` 同比例（站姿发顶到鞋底 512 px），不缩放 | 游戏内 512 px = 世界 64 = 屏幕 128 px |
| 朝向 | **朝右侧视** | 朝左由引擎翻转；义体和针会镜像到另一侧，已接受 |
| 脚底基线 | 着地张（01–03、05–07）最低不透明像素行 = **第 560 行** | 底部留 16 px；检查工具允许 ±2 |
| 腾空张 | 04、08 双脚离地，最低像素在 560 行之上 | 不检查基线 |
| 横向锚点 | 躯干中线（胯部）在 **x = 384** | 8 张对齐这条线，引擎按画布中心翻转 |
| 出界 | 发梢、针尖、下摆都不能碰到画布边 | 检查工具查四边 |

## 4. 8 张姿势

| 张 | 姿势 | 对应 v3 | 要点 |
|---|---|---|---|
| 01 | 右脚着地（contact） | f1 | 步幅最大，前脚跟着地 |
| 02 | 下沉（down） | f2–3 | 重心最低，头顶最低 |
| 03 | 经过（passing） | f4–5 | 后腿从支撑腿旁摆过 |
| 04 | 腾空（up） | f6 | 双脚离地，头顶最高 |
| 05 | 左脚着地 | f7 | 与 01 对称（换腿），不是复制 |
| 06 | 下沉 | f8–9 | 同 02 |
| 07 | 经过 | f10–11 | 同 03 |
| 08 | 腾空 | f12 | 同 04；与 01 首尾相接 |

- **节奏**：每张停 5 个逻辑帧（60 fps），一个循环 40 帧 = 0.667 s；每步约 73 世界 px（≈ 1.15 身高）。v3 上的"12 帧循环 = 1 s = 220 px"不用。节奏写在 `data/anim/zhen_frames.tres`，以后可按张调停留帧数。
- **头部起伏**：下沉最低、腾空最高，上下幅度 ≤ 16 px（屏幕 4 px）。
- **手**：针在右手反握、拖在身后（v3 画法）；左义体前臂握拳在前摆。针长约 148 px（屏幕 37 px）。

## 5. 一致性与可读性（`16` §3、`27` §3）

1. **大形锁定**：以 01 为基准，头发外形、外套下摆只随动作摆动，不每张重画轮廓。v3 的 f12 与 f1 头发差异大，这次要收住。
2. **不要大面积纯黑**：头发、背心、裤子、靴子明度 ≥ 20%（深灰褐）。
3. **不画轮廓光**：青色/品红轮廓光由引擎加。
4. **细节为剪影让路**：裤子破洞、碎边、碎发概括掉；保留识别点——左臂义体、腰侧双线轴（青/红）、针与青线、左肩红线。
5. **只画角色**：不画地面线、阴影、标注、速度线。

## 6. 检查与验收

在 `05_游戏工程/` 下运行：

```bash
godot --headless --path . -s res://tools/check_frames.gd
```

自动检查画布尺寸、透明底、出界、着地张基线；输出 8 张并排图和洋葱皮叠图（路径见输出）。

```bash
godot --path . res://tools/sprite_preview.tscn
```

纯黑 / 纯白 / 雨市夜色三种背景，128 px 与 96 px 两个尺寸循环播放；Space 暂停，← → 逐张。进 `rain_hub` 跑一圈看实际效果。

**门禁**（用户判定，结果写 `06_测试/15_跑步试点.md`）：

1. 自动检查全过。
2. 洋葱皮叠图里头发、下摆不抖。
3. 三种背景、128 px 下一眼读出剪影、朝向和识别点。
4. 平均工时 ≤ **0.6 h/张**（含返工）。0.6 来自：玩家动画约 60 h（美术预算 250 h 的约四分之一，估算）÷ 约 105 张。
