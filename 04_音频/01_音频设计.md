# 《无缝》音频设计

> 版本：v0.1（切片）
> 工具：Godot 4.7 AudioStreamPlayer / AudioServer / AudioEffect；音频总线在 `default_bus_layout.tres`。

---

## 1. 总线架构

| 总线 | 用途 | 目标电平 | 效果 |
|---|---|---|---|
| Master | 总输出 | -1 dBFS 峰值 | Limiter（-1 dB） |
| Music | 音乐 | -6 dB | Compressor（轻） |
| SFX | 音效 | -3 dB | 无 |
| Ambience | 环境 | -12 dB | LowPass（可选） |
| UI | 界面 | -8 dB | 无 |
| Voice | 人声/阿绫 | -4 dB | De-esser（可选） |

- 所有总线挂 Limiter 防削波；Music 在 Boss/接管时 duck 到 -10 dB，SFX 优先。
- 音量设置：Master/Music/SFX/Ambience 四条滑条，0-100 映射到 dB（`linear_to_db`），默认 80。

## 2. 音乐

### 主题
- **雨市·探索**：低频雨声 + 远处列车 + 单一合成器动机（3 音）；BPM 72；留白多。
- **雨市·战斗**：加入打击乐（工业采样）+ 低音 ostinato；BPM 96；不盖过弹反音。
- **阿绫接管**：探索/战斗层之上叠“故障层”（碎拍、失真、反向音）；BPM 不变，密度翻倍。
- **裁断者**：三阶段三层——
  - P1：节拍器般的尺声 + 低音脉冲；BPM 100。
  - P2：加入警报/金属刮擦；BPM 100，密度+。
  - P3：加入人声采样（无词）/心跳；BPM 100，失真。
- **序章/结尾**：单一钢琴/合成器 + 雨；不煽情。

### 自适应实现
- 每首音乐拆 2-4 个 stem（节奏/和声/旋律/故障），用 `AudioStreamPlayer` 同步播放，按战斗状态/同步率调音量。
- 切换用 0.5-1.0 s 淡入淡出；Boss 阶段切换用 0.2 s，允许硬切。
- 节拍同步：Boss 攻击/弹反提示可对齐 BPM 100（0.6 s/拍），但不强制；手感优先。

## 3. 音效清单

| 事件 | 音色 | 时长 | 变化 |
|---|---|---|---|
| 轻击命中 | 钝器+布料 | 0.08 s | 3 个随机变体，音高 ±5% |
| 重击命中 | 金属+低频 | 0.15 s | 2 变体 |
| 弹反普通 | 金属“叮”+ 线绷紧 | 0.12 s | 音高随同步率升高 |
| 弹反完美 | 白噪爆+反向铃声+心跳 | 0.25 s | 唯一，不随机 |
| 弹反失败 | 线断+闷响 | 0.2 s | 2 变体 |
| 缝住敌人 | 线穿过布/金属 | 0.3 s | 随目标材质变 |
| 收线 | 棘轮 | 0.15 s | 循环 |
| 断线 | 弹断+回弹 | 0.2 s | 3 变体 |
| 换人 | 故障+呼吸 | 0.3 s | 阿绫/阿针各一 |
| 接管 | 耳鸣+失真+心跳 | 1.0 s | 进入/退出 |
| 受击 | 闷响+电流 | 0.1 s | 3 变体 |
| 死亡 | 断线+长回声 | 1.5 s | 唯一 |
| 雨 | 循环 | — | 2 层（近/远） |
| 列车 | 循环+多普勒 | 2.0 s | 过站时触发 |
| 霓虹电流 | 循环 | — | 随距离衰减 |
| 脚步 | 湿地面/金属 | 0.08 s | 4 变体，随地面材质 |
| UI 确认/取消/悬停 | 短促电子 | 0.05 s | 统一音色 |

## 4. 阿绫的声音

- **处理**：轻失真 + 短混响 + 偶尔比特粉碎；不是“机器人”，是“信号不稳的人”。
- **同步率**：>30 正常；<30 只有气声/半句；>70 出现花屏/抢话/回声。
- **台词触发**：弹反成功/失败、换人、低血量、进入新区域、Boss 阶段；避免每 5 秒重复。
- **字幕**：所有阿绫台词必须配字幕；字幕颜色与 overlay 一致；可关闭“抖动”。

## 5. 实现要点（Godot）

- `default_bus_layout.tres` 定义总线；`AudioServer.set_bus_volume_db()` 调音量。
- 音效池：`AudioStreamPlayer` 复用 8-16 个，避免频繁 `new()`；2D 用 `AudioStreamPlayer2D` + `max_distance`。
- 音乐：每个 stem 一个 `AudioStreamPlayer`，`play()` 前对齐 `get_playback_position()`；用 `Tween` 调 `volume_db`。
- 弹反音必须在判定成功当帧播放，不等动画；用 `AudioStreamPlayer.play()` 直接触发。
- 总线电平用 `AudioEffectLimiter` 防削波；导出前用 `ffmpeg`/Audacity 检查峰值。
- 所有音频文件 48 kHz/16-bit WAV/OGG；循环点用 `loop_mode` 设置；命名 `sfx_parry_perfect_01.ogg`。

## 6. 验收

- [ ] 六条总线在游戏内可调，静音/独奏有效。
- [ ] 弹反音与判定帧误差 < 1 帧（16.7 ms）。
- [ ] 战斗音乐切换无爆音/无 gap。
- [ ] 阿绫台词字幕与音频同步。
- [ ] 所有音频有来源/授权登记。
- [ ] 戴耳机时低频不浑浊；外放时弹反音可辨。
