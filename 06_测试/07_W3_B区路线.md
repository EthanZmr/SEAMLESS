## 1. 目标

把 W2 的攀爬、墙跳、抓边、缝线钩整合进雨市 B 区，而不是继续堆原型：

- 玩家从 A 区进入 B 后，能看见一条“高路线”和一条“低路线”。
- 高路线：跳上维护塔 → W 攀爬 → 翻上屋顶 → 钩索过高桥 → 落到 C 高台。
- 中段可选：两塔之间的墙跳井，作为第三条微路线。
- 低路线：地面 + 660/1040 平台，敌人更多但不需要新动作。
- 两条路都汇入 C，不做强制门禁；W3 先验证“路线选择”，不扩关卡。

## 5. 真人验收（待做）

按这个顺序走一遍，目标 90 秒内到 C：

1. 从 A 走到 B，跳起贴塔右面，按 W：应进入攀爬，不穿墙。
2. 爬到顶，按 Space / 方向翻上屋顶；不应卡在塔顶。
3. 在屋顶按 H 钩住 `(900,170)` 锚点，松开后落到高桥；不应穿桥。
4. 从高桥落到 C 高台，再下到 C 街；不应卡在重叠平台。
5. 回到 B 地面，走低路线；确认低路线仍可通，不被高路线几何堵死。
6. 可选：从墙跳井左右交替上到高桥。

门禁：
- 不出现卡死、穿墙、抓边失败导致的 soft lock。
- 高路线明显比低路线快，但不是唯一路线。
- 玩家在 3 分钟内能说出“攀爬/墙跳/钩索”各自解决什么。

## 5.1 重叠锚点钩跳热修

- 问题：角色与钩索锚点重叠时，钩跳只出一次，二段跳失效。
- 根因：`_end_hook(true)` 设 0.18s 锁，而跳跃缓冲只有 0.12s；第二下 Space 在锁内被丢掉。
- 修复：`HOOK_JUMP_LOCK=0.08`，并让“断钩免费跳”绕过锁立即触发；新增 `test_movement` 重叠锚点用例。
- 现在：69/69 移动测试通过。

## 5.2 钩索遮挡 / 卡平台热修

- 问题：角色与锚点之间隔着小跳台时，按 H 会被吸在跳台下面，不能动。
- 根因：钩索状态每帧把速度指向锚点，`move_and_slide()` 撞到平台后没有退出 HOOK。
- 修复：HOOK 分支 `move_and_slide()` 后检查 `get_slide_collision_count()`，撞到东西立即 `_end_hook(false)`、速度归零、提示“钩索断了”。
- 测试：新增 `_test_hook_collision_detach`；移动 69/69。
- 说明：没有做起点视线检测；优先保证“能钩且不卡死”，不做“隔墙拒绝”。

## 5.4 真人验收结果（2026-10-20）

- 高路线、低路线都走过；没有卡死、穿墙、抓边失败。
- 90 秒未计时；用户反馈“也不远，地图有点小”。记为**路线通过，时间项待补测**。
- 可读性问题：用户不确定哪些墙能攀爬。当前规则是**只有绿色梯缝/维护面可攀爬；任意实心墙可墙跳**，但白盒标记不够显眼。
- 已把 B 区提示改为“高路线：绿色梯缝 W 攀爬 → 钩索；墙跳任意墙面”。
- 结论：W3 路线门禁**通过（条件项：时间未测、地图密度偏小）**，可进入 W4 战斗扩展；W6–7 重排雨市时再扩大 B 区。
