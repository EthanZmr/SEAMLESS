## 1. 设计约束

- 玩家度量按当前代码：跑速 220，跳速 -600，重力 1400；满跳高约 128px，水平跳距约 188px，冲刺 560。
- 钩索射程 320px；绿色梯缝可攀爬，任意实心墙可墙跳。
- 不在 W6-1 增加新系统；只重排 C 区几何、敌人和第三个接缝。
- A/B 的入口、教学和高低路线保持可通，避免把已验证的 W3/W4 内容推翻。

## 3. 路线与节奏

1. **A 诊所后巷**：安全起步，保留无敌人。
2. **B 雨市入口**：低路线走地面；高路线绿梯 → 屋顶 → B 钩索高桥。B 屋顶不再额外加守卫，避免和 C 的敌人密度叠在一起。
3. **C 霓虹巷地面**：截线者 + 补丁；玩家可以选择继续贴地。
4. **C 竖井**：双墙交替跳；中途没有安全平台，失败会落回地面，但不掉出关卡。
5. **C 屋顶**：清道夫；打赢后从屋顶看得到猫道、钩点和猫道右端的电力缝。
6. **C 猫道**：钩索到达；向右走到电力接缝；从猫道右端落回 C/D 交界。
7. **D 磁轨站**：原针眼检查点保留在 1720，作为 C 段结束后的休息点。

强度曲线：A 0.1 → B 0.45 → C 地面 0.5 → C 竖井 0.65 → C 屋顶 0.7 → 猫道 0.3（奖励/喘息）→ D 0.2（针眼）。
