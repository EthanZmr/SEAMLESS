# 《无缝》SEAMLESS

> 2147 年，垂直巨城。缝线师阿针靠修义体、补记忆为生；她脑子里住着另一个人的意识——无缝集团首席架构师白露的妹妹。集团要把旧城全部回收，重建成一座没有接缝的完美城市；阿针要决定：把脑子里的声音还回去，还是留着它，继续做一个拼起来的人。

Godot 4.7.2 · 2D · GDScript · 单人横版 Q 版赛博朋克 2D 动作

## 运行

需要 Godot 4.7.2（`godot` 在 PATH 里）。

```bash
cd 05_游戏工程
godot --path . --editor --quit     # 首次导入（生成 .godot/ 与本地化二进制）
godot --path .                     # 运行
godot --path . -- --log            # 运行并把关键事件写进 user://logs/
```

默认窗口 1280×720，内部 1920×1080。序章 `Enter / J / 空格` 继续，`Esc` 跳过。

## 门禁

```bash
cd 05_游戏工程
bash tools/test_all.sh      # 22 个无头测试套件
bash tools/lint.sh          # gdlint + 全量编译检查
bash tools/export_check.sh  # 三平台导出并检查产物
```

`test_all.sh` 会先 `--import` 重建 class cache，再按文件头自动判断每个套件该用
`-s` 还是 `.tscn` 方式跑。当前基线：**22 个套件 0 失败**，lint 无问题，
Windows / Linux / Web 三平台导出均通过。

## 工程架构

分层（L0 世界 → L1 规则 → L2 实体 → L3 表现 → L4 基础设施）、数据分离方案、
以及"为什么现在不做 ECS / 行为树 / DI / 对象池"的完整论证，见
`05_游戏工程/README.md` 与 `05_游戏工程/docs/architecture-v1.md`。

内容与数值不写在脚本里：攻击帧表、玩家数值、同步规则是 `.tres`；关卡几何、
对白、关卡清单是 `.json`；界面文案是 `.csv`（`--import` 生成 `.translation`）。
加载失败一律静默回退到脚本内置默认值，不会因为数据文件缺失而崩。
